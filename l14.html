Chapter 2 by hand

Linear, separable, exact, exact after μ.

Today: what to do when none of them applies.

When no formula exists

dydt = t2 + y2,   y(0) = 0

Linear? No: y2.

Separable? No: a sum does not split into f(t)g(y).

Exact, or exact after μ? M = t2 + y2, N = −1: the test fails. The first ratio is −2y (not only t); the second is −2y/(t2 + y2) (not only y). No μ.

But the theorem of §2.4 says a solution exists: f and fy are continuous everywhere.

It exists, and we cannot write it down. Most equations in science are like this.

New goal: not a formula for y(t), but good numbers for it.

↳ the direction field already knows the answer. We follow it.

The idea — follow the tangent line for a short step

dydt = f(t, y),   y(t0) = y0

At the starting point we know the position (t0, y0) and the slope there: f(t0, y0).

A point and a slope give a line, the tangent line:

y = y0 + f(t0, y0)(t − t0)

Near t0 the solution and its tangent line are close. So walk along the line for a short time h.

Then stop, compute the new slope from the equation, and turn.

Move straight, stop, compute the new slope, turn. Repeat.

↳ now every line of the formula.

Euler’s formula, line by line

y = y0 + f(t0, y0)(t − t0)  the tangent line at the start

Step 1: from t0 to t1

t1 = t0 + h

y1 = y0 + f(t0, y0)(t1 − t0)

y1 = y0 + h f0  write f0 = f(t0, y0)

Step 2: the same, from the new point

y2 = y1 + h f1,   f1 = f(t1, y1)

Every step

tn+1 = tn + h

yn+1 = yn + h f(tn, yn)

y1 is only an approximation, and step 2 uses it. Errors carry forward.

Number of steps from t0 to T: N = (T − t0)/h.

↳ the recipe, then Boyce’s Example 1.

The recipe — one table

  1. Solve for y′: write the equation as y′ = f(t, y).
  2. List t0, y0, h, and the number of steps N.
  3. Each row: compute fn = f(tn, yn), then yn+1 = yn + hfn.
  4. Repeat until tn reaches the target time.

Checks that cost nothing

The sign of fn says up or down. If fn > 0, the next y must be larger.

Keep five or six digits. Do not round early: every row uses the previous one.

When an exact solution is known, compare. That is how we measure the error.

Every step lands on a neighboring solution

Three solutions of y′ = 4 − t + 2y, starting at 0.8, 1 and 1.2.

They start 0.2 apart and move away from each other fast: the e2t term.

Each Euler step makes a small error, so the next step follows a neighboring solution.

diverging family: small errors grow  Example 4

Converging family: errors fade. Diverging family: errors grow.

↳ how a computer runs Euler’s method.

In practice — a loop

input  f, t0, y0, h, N

t ← t0,   y ← y0

repeat N times:

    m ← f(t, y)

    y ← y + hm

    t ← t + h

output  t, y

The slope m is computed before y changes. Swap the two lines and the method is wrong.

Real software uses better methods than Euler (§8 in Boyce), but every one of them is built on this loop.

On an exam: three or four rows by hand, with a calculator. Show fn on each row.

tn+1 = tn + h,   yn+1 = yn + h f(tn, yn)

Idea: follow the tangent line for one step, then read the new slope.

Error ≈ C·h: halve the step, halve the error.
