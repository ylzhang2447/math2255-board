Chapter 3: equations with a second derivative y″. They describe springs, circuits, and anything that vibrates.

Today: ay″ + by′ + cy = 0

Second-order linear equations

y″ = f(t, y, y′)  second order: the highest derivative is y″

Linear

y″ + p(t) y′ + q(t) y = g(t)

y, y′, y″ appear only to the first power, times functions of t.

P(t) y″ + Q(t) y′ + R(t) y = G(t)

Divide by P(t) ≠ 0 to get the line above.

Homogeneous

g(t) = 0 for every t. Otherwise the equation is nonhomogeneous.

Constant coefficients

P, Q, R are numbers. Most of Chapter 3 is about this case.

Today: ay″ + by′ + cy = 0,  a ≠ 0

Homogeneous first. §3.5 and §3.6 build the nonhomogeneous case on it.

↳ four equations to sort.

Think about it — sort these four

1.  y″ + t y′ + 3y = 0

linear, homogeneous. The coefficient t is not a constant.

2.  y″ − 4y = et

linear, nonhomogeneous. g(t) = et ≠ 0.

3.  y″ + y y′ = 0

nonlinear. y times y′ is a product of unknowns.

4.  2y″ − 5y′ + 2y = 0

linear, homogeneous, constant coefficients. Today’s type.

↳ why a second-order equation needs two conditions.

Two constants, two conditions

y″ = 6t  the simplest second-order equation

Integrate once

y′ = 3t2 + c1

Integrate again

y = t3 + c1t + c2

Two integrations, two constants. One condition cannot fix both.

y(0) = 1  ⇒  c2 = 1;   y′(0) = −2  ⇒  c1 = −2

y = t3 − 2t + 1

Initial conditions for a second-order equation

y(t0) = y0,   y′(t0) = y0′

The first gives the point where the graph starts. The second gives its slope at that point.

Why Chapter 2 is not enough

Every Chapter 2 method starts from y′ = f(t, y). None of them handles y″.

Here we could integrate twice because the right side has no y. In y″ = 9y it does.

↳ so we guess.

A first equation — solved by guessing

y″ − 9y = 0  that is, y″ = 9y

Two derivatives must give 9 times the function

y = e3t:  y′ = 3e3t,  y″ = 9e3t  ✓

y = e−3t:  y′ = −3e−3t,  y″ = 9e−3t  ✓

Constant multiples work too: 5e3t, −2e−3t.

y = c1e3t + c2e−3t  and sums?

Check the sum

y″ = 9c1e3t + 9c2e−3t

= 9(c1e3t + c2e−3t) = 9y  ✓

Two constants, which is what the last page said we need.

Exponentials work because the derivative of ert is a number times ert.

Two ideas: exponentials, and sums of solutions.

↳ why sums of solutions are solutions.

Superposition — sums of solutions are solutions

y1, y2 solve ay″ + by′ + cy = 0  ⇒  so does c1y1 + c2y2

Put y = c1y1 + c2y2 into the left side

a(c1y1 + c2y2)″ + b(c1y1 + c2y2)′ + c(c1y1 + c2y2)

= c1(ay1″ + by1′ + cy1) + c2(ay2″ + by2′ + cy2)

= c1·0 + c2·0 = 0  ✓

The derivative of a sum is the sum of the derivatives, and constants move in front.

It needs the 0 on the right

y″ + y = 1:  y1 = 1 is a solution  0 + 1 = 1

2y1 = 2:  0 + 2 = 2 ≠ 1  not a solution

Superposition is a fact about linear homogeneous equations.

Find two exponential solutions, then combine them.

↳ which exponentials? Every line of the derivation.

The characteristic equation — every line

ay″ + by′ + cy = 0  guess y = ert, with r a number to find

Differentiate the guess

y = ert

y′ = rert

y″ = r2ert

Substitute all three

a(r2ert) + b(rert) + c(ert) = 0

Factor ert from every term

ert(ar2 + br + c) = 0

ert ≠ 0 for every t  an exponential is never zero

ar2 + br + c = 0   the characteristic equation

If r solves it, then y = ert solves the differential equation.

y″ − 9y = 0:  r2 − 9 = 0,  r = ±3  ✓ our guesses

↳ a quadratic has two roots. Three cases.

Two roots, three cases

r = −b ± √b2 − 4ac2a

b2 − 4ac > 0: two real, different roots. Today.

b2 − 4ac < 0: complex roots. Friday, §3.3.

b2 − 4ac = 0: one repeated root. §3.4, next week.

Today: real, different roots

y1 = er1t,   y2 = er2t

y = c1er1t + c2er2t

This is the general solution: every solution has this form. §3.2 explains why.

Because r1 ≠ r2, any pair of initial conditions fixes exactly one pair c1, c2.

↳ the recipe.

The recipe

  1. Characteristic equation. y″ → r2, y′ → r, y → 1.
  2. Solve it. Factor, or use the quadratic formula. Two real roots r1 ≠ r2.
  3. General solution: y = c1er1t + c2er2t.
  4. Initial conditions: differentiate y, put t = t0 into y and y′. That is a 2 × 2 system for c1, c2.
  5. Solve the system and write the answer with numbers.

You can always check

Put each root into ar2 + br + c. It must give 0.

Put t0 into your y and y′. They must give the two initial values.

A missing term means a zero coefficient

y″ − 16y = 0  →  r2 − 16 = 0  no r term

↳ four quick characteristic equations.

Think about it — characteristic equations

1.  y″ + 2y′ − 15y = 0

r2 + 2r − 15 = (r + 5)(r − 3) = 0:  r = −5, 3

2.  y″ − 25y = 0

r2 − 25 = 0:  r = ±5  not r2 − 25r

3.  3y″ + y′ − 2y = 0

3r2 + r − 2 = (3r − 2)(r + 1) = 0:  r = 23, −1

4.  y″ + 7y′ = 0

r2 + 7r = r(r + 7) = 0:  r = 0, −7

↳ number 4 has a root 0. Example 4 shows what that means.

Example 1 — the general solution

y″ + 5y′ + 6y = 0

1  characteristic equation

r2 + 5r + 6 = 0

2  solve

(r + 2)(r + 3) = 0

r1 = −2,   r2 = −3  real, different

3  general solution

y = c1e−2t + c2e−3t

Check e−2t

y′ = −2e−2t,   y″ = 4e−2t

4e−2t + 5(−2e−2t) + 6e−2t = (4 − 10 + 6)e−2t = 0  ✓

The number in the parentheses is r2 + 5r + 6 at r = −2. That is why the check works.

e−3t:  9 − 15 + 6 = 0  ✓

↳ now add two initial conditions.

Example 2 — an initial value problem

y″ + 5y′ + 6y = 0,   y(0) = 2,   y′(0) = 3

3  from Example 1, and its derivative

y = c1e−2t + c2e−3t

y′ = −2c1e−2t − 3c2e−3t

4  put in t = 0, where e0 = 1

y(0) = c1 + c2 = 2

y′(0) = −2c1 − 3c2 = 3

5  solve the system

2 × first:  2c1 + 2c2 = 4

add the second:  −c2 = 7  ⇒  c2 = −7

c1 = 2 − c2 = 2 + 7 = 9

y = 9e−2t − 7e−3t

check:  9 − 7 = 2  ✓   −18 + 21 = 3  ✓

↳ what does it look like?

Example 2 — up first, then down to 0

y = 9e−2t − 7e−3t

Starts at height 2 with slope 3, so it rises first.

The top: where y′ = 0

y′ = −18e−2t + 21e−3t = 0

multiply by e3t:  −18et + 21 = 0

et = 76  ⇒  t = ln(7/6) ≈ 0.15

y = 9(67)2 − 7(67)3 = 10849 ≈ 2.2

Both exponents negative: y → 0.

↳ a leading coefficient that is not 1.

Example 3 — a ≠ 1 and fractional roots

4y″ − 8y′ + 3y = 0,   y(0) = 2,   y′(0) = 12

1, 2  characteristic equation and roots

4r2 − 8r + 3 = 0

(2r − 1)(2r − 3) = 0  check: 4r2 − 6r − 2r + 3

r1 = 12,   r2 = 32

3  general solution and its derivative

y = c1et/2 + c2e3t/2

y′ = 12c1et/2 + 32c2e3t/2

4  the system at t = 0

c1 + c2 = 2

12c1 + 32c2 = 12  ⇒  c1 + 3c2 = 1  times 2

5  solve

subtract:  2c2 = −1  ⇒  c2 = −12,   c1 = 52

y = 52et/2 − 12e3t/2

As t → ∞, e3t/2 grows faster, and its coefficient is negative: y → −∞.

↳ a root equal to 0.

Example 4 — a root equal to 0

y″ + 2y′ = 0,   y(0) = 3,   y′(0) = −4  no y term

1, 2  no y term, so no constant term

r2 + 2r = 0

r(r + 2) = 0  ⇒  r1 = 0,  r2 = −2

3  use e0t = 1

y = c1e0t + c2e−2t = c1 + c2e−2t

y′ = −2c2e−2t  c1 is a constant, so its derivative is 0

4, 5  the system

y(0) = c1 + c2 = 3

y′(0) = −2c2 = −4  ⇒  c2 = 2

c1 = 3 − 2 = 1

y = 1 + 2e−2t

As t → ∞, y → 1. A zero root gives a constant term.

Long-term behavior — which term wins as t → ∞

y = c1er1t + c2er2t

Both roots negative: both terms go to 0, so y → 0. Example 2.

A positive root: that term grows without bound, unless its coefficient is 0. The sign of the coefficient decides +∞ or −∞. Example 3.

Roots 0 and negative: y → c1, a constant. Example 4.

Look at the larger root and its coefficient.

↳ choose the coefficient to stop the growth.

Example 5 — a parameter

y″ − y′ − 6y = 0,   y(0) = 1,   y′(0) = β  find β so that y stays bounded as t → ∞

r2 − r − 6 = (r − 3)(r + 2) = 0  ⇒  r = 3, −2

y = c1e3t + c2e−2t

y′ = 3c1e3t − 2c2e−2t

c1 + c2 = 1,   3c1 − 2c2 = β

2 × first + second:  5c1 = 2 + β

c1 = 2 + β5,   c2 = 1 − c1 = 3 − β5

Which term grows?

e3t → ∞. The solution stays bounded only if its coefficient is 0.

c1 = 0  ⇔  2 + β = 0  ⇔  β = −2

β = −2:  y = e−2t → 0

β > −2:  c1 > 0, y → +∞

β < −2:  c1 < 0, y → −∞

↳ irrational roots.
