From homogeneous to nonhomogeneous

Done: ay″ + by′ + cy = 0

two real roots, complex roots, one repeated root

Each time: two solutions y1, y2 and y = c1y1 + c2y2.

Today: a right-hand side

ay″ + by′ + cy = g(t),   g ≠ 0

g is a forcing: a push on a spring, a voltage in a circuit.

Two questions: what does the general solution look like, and how do we find one solution?

Call it out — the homogeneous solution

1.  y″ − 3y′ − 4y = 0

2.  y″ + 4y = 0

3.  y″ − 4y′ + 4y = 0

1.  (r − 4)(r + 1):  c1e4t + c2e−t

2.  r = ±2i:  c1 cos 2t + c2 sin 2t

3.  r = 2, twice:  (c1 + c2t)e2t

↳ today we need this step in every problem.

The structure of the solution

L[y] = y″ + py′ + qy = g(t)

Two solutions of the same equation

L[Y1] = g,   L[Y2] = g

L[Y1 − Y2] = g − g = 0  L is linear

So Y1 − Y2 solves the homogeneous equation:

Y1 − Y2 = c1y1 + c2y2

Theorem 3.5.2

y = c1y1 + c2y2 + Y = yc + Y

yc: the general solution of the homogeneous equation.

Y: any one solution of the full equation, a particular solution.

↳ why adding them works, in plain words.

Why yc + Y works

L[y] = y″ + py′ + qy = g(t)

Put y = yc + Y into the left side

L[yc + Y] = L[yc] + L[Y]  L is linear

L[yc] = 0  yc solves the homogeneous equation

L[Y] = g  Y solves the full equation

L[yc + Y] = 0 + g = g  ✓

In plain words

yc carries the two constants c1, c2. It adds nothing to the right side.

Y produces the right side g. It has no constants.

Together: the right side is correct, and there are two constants for the two initial conditions.

Y alone cannot match initial conditions. yc alone gives 0 on the right, not g.

↳ the steps.

The steps

ay″ + by′ + cy = g(t)

1. Solve the homogeneous equation (g replaced by 0): yc.

2. Find one particular solution Y.

3. y = yc + Y.

4. Initial conditions: put them into the whole y, then solve for c1, c2.

The usual mistake

Using the initial conditions on yc alone, before adding Y.

y(0) = yc(0) + Y(0)  Y(0) is usually not 0

Step 1 is chapter 3 so far. Step 2 is new.

↳ how to find Y.

Undetermined coefficients — the idea

constant a, b, c, and g is an exponential, a polynomial, or a sine or cosine

Why a guess can work

Derivatives of these functions are functions of the same kind.

So aY″ + bY′ + cY has the same form as Y. Choose the coefficients so it equals g.

The guesses

g = eαt  →  Y = Aeαt

degree n polynomial  →  all powers up to tn

cos βt or sin βt  →  A cos βt + B sin βt

Two rules

For sine or cosine, always use both.

For a polynomial, use every power down to the constant.

Wednesday: sums of these, and the case when the guess fails.

↳ one example of each kind.

Example 1 — an exponential

y″ − 3y′ − 4y = 3e2t

Guess and differentiate

Y = Ae2t,  Y′ = 2Ae2t,  Y″ = 4Ae2t

Put in

(4A − 6A − 4A)e2t = 3e2t

−6A = 3  ⇒  A = −12

Y = −12e2t

General solution (yc from the opening, number 1)

y = c1e4t + c2e−t − 12e2t

Check: 2 is not a root of r2 − 3r − 4, so the guess works.

↳ a sine.

Example 2 — a sine

y″ − 3y′ − 4y = 2 sin t

Guess both cosine and sine

Y = A cos t + B sin t

Y′ = −A sin t + B cos t,   Y″ = −A cos t − B sin t

Put in, and collect cos and sin

cos t:  −A − 3B − 4A = −5A − 3B

sin t:  −B + 3A − 4B = 3A − 5B

Match with 0 cos t + 2 sin t

−5A − 3B = 0,   3A − 5B = 2

A = 317,   B = −517

Y = 317 cos t − 517 sin t

g has no cosine, but Y does. With sin t alone, the cos equation would say 3B = 0.

↳ why can we match cos and sin separately?

Why we can match coefficients

If  P cos t + Q sin t = 0  for every t

Pick two values of t

t = 0:  P·1 + Q·0 = 0  ⇒  P = 0

t = π/2:  P·0 + Q·1 = 0  ⇒  Q = 0

Both coefficients must be zero.

This is linear independence of cos t and sin t, from §3.2.

Example 2 again

(−5A − 3B) cos t + (3A − 5B) sin t

= 0·cos t + 2·sin t

cos:  −5A − 3B = 0,   sin:  3A − 5B = 2

The same idea works for powers of t and for exponentials: that is why we compare term by term.

↳ one more, with sin 2t.

Example 3 — sin 2t

y″ − 4y′ − 12y = sin 2t

Guess, and two derivatives

Y = A cos 2t + B sin 2t

Y′ = −2A sin 2t + 2B cos 2t

Y″ = −4A cos 2t − 4B sin 2t

Collect

cos 2t:  −4A − 8B − 12A = −16A − 8B

sin 2t:  −4B + 8A − 12B = 8A − 16B

Match with 0 cos 2t + 1 sin 2t

−16A − 8B = 0  ⇒  B = −2A

8A + 32A = 1  ⇒  A = 140,  B = −120

Y = 140 cos 2t − 120 sin 2t

The chain rule brings a factor 2 into every derivative. Keep track of it.

Example 4 — a polynomial

y″ − 3y′ − 4y = 4t2 − 1

Degree 2: use every power

Y = At2 + Bt + C,   Y′ = 2At + B,   Y″ = 2A

Put in

2A − 3(2At + B) − 4(At2 + Bt + C)

= −4At2 + (−6A − 4B)t + (2A − 3B − 4C)

Match with 4t2 + 0t − 1

t2:  −4A = 4  ⇒  A = −1

t:  −6A − 4B = 0  ⇒  B = 32

1:  2A − 3B − 4C = −1  ⇒  C = −118

Y = −t2 + 32t − 118

↳ everything together, with initial conditions.

Example 5 — the whole problem

y″ − y′ − 2y = 4t,   y(0) = 0,   y′(0) = 0

1  yc

(r − 2)(r + 1) = 0:  yc = c1e2t + c2e−t

2  Y = At + B

−A − 2(At + B) = 4t:  −2A = 4,  −A − 2B = 0

A = −2,  B = 1:  Y = −2t + 1

3, 4  the whole y, then the conditions

y = c1e2t + c2e−t − 2t + 1

y(0) = c1 + c2 + 1 = 0,   y′(0) = 2c1 − c2 − 2 = 0

add: 3c1 − 1 = 0,  c1 = 13,  c2 = −43

y = 13e2t − 43e−t − 2t + 1

↳ the +1 and the −2 from Y are in these equations.

Find the mistake

y″ + 4y = 8,   y(0) = 0,   y′(0) = 0

A student’s work

yc = c1 cos 2t + c2 sin 2t,   Y = 2

yc(0) = c1 = 0,   yc′(0) = 2c2 = 0

y = 0 + 2 = 2

Check: y(0) = 2, not 0. Something is wrong.

The mistake

The conditions were used on yc alone, before adding Y.

Correct

y = c1 cos 2t + c2 sin 2t + 2

y(0) = c1 + 2 = 0,   y′(0) = 2c2 = 0

y = 2 − 2 cos 2t

True or false?

1.  If Y1 and Y2 both solve L[y] = g, then Y1 + Y2 also solves it.

2.  For g = 3 sin 2t, the guess Y = A sin 2t always works.

3.  For g = t2, the guess Y = At2 is enough.

4.  Two different particular solutions give the same general solution.

5.  Use the initial conditions on yc first, then add Y.

1.  false  L[Y1 + Y2] = 2g

2.  false  a y′ term brings cos 2t

3.  false  At2 + Bt + C

4.  true  they differ by a solution of the homogeneous equation

5.  false  the whole y, at the end

↳ number 4 is Theorem 3.5.1 again.
