When the function is not written in t − c

ℒ{uc(t)g(t)} = e−csℒ{g(t + c)}

Why

g(t) = g((t − c) + c)

So g(t) = f(t − c), where f(t) = g(t + c).

ℒ{uc(t)g(t)} = ℒ{uc(t)f(t − c)} = e−csℒ{f}

How to use it

1. Read c from the step.

2. Replace t by t + c in g, and simplify.

3. Transform that, and multiply by e−cs.

↳ three examples.

Example 1 — ℒ{u1(t)t2}

c = 1,   g(t) = t2

2. Replace t by t + 1

g(t + 1) = (t + 1)2 = t2 + 2t + 1

3. Transform, multiply by e−s

ℒ{t2 + 2t + 1} = 2s3 + 2s2 + 1s

ℒ{u1(t)t2} = e−s(2s3 + 2s2 + 1s)

The wrong answer e−s·2s3 is the transform of u1(t)(t − 1)2, a different function (Wednesday’s picture).

↳ a sine.

Example 2 — ℒ{uπ/2(t) sin t}

c = π/2,   g(t) = sin t

2. Replace t by t + π/2

g(t + π/2) = sin(t + π/2) = cos t

Addition formula: sin(t + π/2) = sin t cos π/2 + cos t sin π/2 = cos t.

3. Transform, multiply by e−πs/2

ℒ{uπ/2(t) sin t} = e−πs/2ss2 + 1

After the shift, the sine became a cosine. Simplify before you transform.

↳ an exponential.

Example 3 — ℒ{u2(t)e3t}

c = 2,   g(t) = e3t

2. Replace t by t + 2

g(t + 2) = e3(t + 2) = e6e3t

e6 is a constant: it moves out of the transform.

3. Transform, multiply by e−2s

ℒ{u2(t)e3t} = e6e−2s1s − 3 = e−2(s − 3)s − 3

↳ now backwards.

Going backwards

ℒ−1{e−csF(s)} = uc(t)f(t − c)

Three steps

1. Set e−cs aside and read c.

2. Invert the rest: f(t) = ℒ−1{F}.

3. Replace t by t − c, and multiply by uc(t).

Why

It is the shift theorem read from right to left.

The answer is 0 before t = c: the factor e−cs means “nothing happens until time c”.

↳ a picture of a delay.

What the factor e−cs does

dashed: sin t = ℒ−1{1s2 + 1}.

teal: ℒ−1{e−3ss2 + 1} = u3(t) sin(t − 3).

The same wave, starting at t = 3 instead of 0, and 0 before that.

A factor e−cs in s = a delay by c in t.

↳ two examples.

Two shift rules, side by side

Do not mix them up

e−csF(s) ↔ uc(t)f(t − c)

Look for: a factor e−cs in front.

F(s − a) ↔ eatf(t)

Look for: every s appears as s − a.

Some functions have both, and then we use both.
