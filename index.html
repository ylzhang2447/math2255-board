Differential equation

An equation that contains derivatives of an unknown function.

↳ the unknown is a function — not a number

You already know one

F = ma   and   a = dvdt

⇒  mdvdt = mg − γv

The falling object from §1.1.  unknown = v(t)

Five equations, to classify

(1)  mu″ + γu′ + ku = F(t)  mass on a spring

(2)  a2∂2u∂x2 = ∂2u∂t2  wave

(3)  dxdt = ax − αxy,   dydt = −cy + γxy  predator–prey

(4)  y‴ + 2ety″ + yy′ = t4

(5)  d2θdt2 + gL sin θ = 0  pendulum

Three questions

1.  How many derivatives?

2.  How many variables?

3.  Is it linear?

Ordinary derivatives → an ordinary differential equation (ODE)

(2)  a2∂2u∂x2 = ∂2u∂t2  wave

Partial derivatives → a partial differential equation (PDE)

PDE:  (2)

In this course: one ODE, one unknown function.

Linear equations

Linear if we can write it as

a0(t)y(n) + a1(t)y(n−1) + … + an(t)y = g(t)

Three things to check

  1. No products of y and its derivatives. (no yy′)
  2. No powers except the first. (no y2)
  3. y is never inside another function. (no sin y)

The coefficients can be anything.

↳ only y and its derivatives decide this

linear:  (1) spring   (2) wave

nonlinear:  (4) ← yy′   (3) ← xy   (5) ← sin θ

Why we care: linearization

The pendulum is nonlinear because of sin θ.

d2θdt2 + gL sin θ = 0

But if θ is small, then  sin θ ≈ θ.

d2θdt2 + gL θ = 0  linear

We can solve this one. We will, in Chapter 3.

↳ this is called linearization

Solution

A solution on α < t < β is a function that makes the equation true for every t there.

↳ the interval is part of the answer

Finding is hard. Checking is easy.

Does  y1(t) = cos t  solve  y″ + y = 0 ?

y1′ = −sin t     y1″ = −cos t

y1″ + y1 = −cos t + cos t = 0 ✓

to check a solution, substitute it in

How many solutions?

The field mouse equation:

dpdt = 0.5p − 450

has the solution

p(t) = 900 + cet/2   c any constant

There are infinitely many solutions.

So — which one do we want?

Picking one solution

Suppose there were 850 mice at time zero.

p(0) = 850

This is an initial condition.

Put it in

850 = 900 + ce0 = 900 + c

c = −50

p(t) = 900 − 50et/2

One equation. One condition. One solution.

Initial value problem

A differential equation together with an initial condition is an

initial value problem  (IVP).

dpdt = 0.5p − 450,   p(0) = 850

How many conditions?  Same as the order.

first order → one     second order → two

The general solution

Both models have the same shape:

dydt = ay − b

Its solution is always

y(t) = ba + ceat

This is the general solution — every solution has this form.

With an initial condition

y(0) = y0  ⇒  c = y0 − ba

y(t) = ba + (y0 − ba)eat

The pattern

  1. Find the general solution — it contains c.
  2. Put in the initial condition.
  3. Solve for c.

Almost every problem this term is these three steps.
