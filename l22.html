When g is a sum

L[y] = g1(t) + g2(t)

Split the problem

L[Y1] = g1,   L[Y2] = g2

L[Y1 + Y2] = g1 + g2  L is linear

Y = Y1 + Y2

In plain words

Each piece of g gets its own small problem. Solve them one at a time, then add.

This is why we never need a guess with many letters at once.

↳ Monday’s two examples, added.

Example 1 — a sum

y″ − 3y′ − 4y = 3e2t + 2 sin t

Piece 1: g1 = 3e2t  (Monday, Example 1)

Y1 = −12e2t

Piece 2: g2 = 2 sin t  (Monday, Example 2)

Y2 = 317 cos t − 517 sin t

Add

Y = −12e2t + 317 cos t − 517 sin t

No new work: two small problems we already solved.

One big guess Ae2t + B cos t + C sin t gives the same answer, with more algebra.

↳ products, like te2t.

When g is a product

the exponential factor stays; the other factor follows Monday’s rules

The guesses

eαt·(degree n polynomial)  →  eαt·(all powers up to tn)

eαt cos βt or eαt sin βt  →  eαt(A cos βt + B sin βt)

In plain words

Differentiating eαt·(something) gives eαt·(something of the same kind).

So the exponential is a common factor. We match what is left, as on Monday.

↳ an example.

Example 2 — a polynomial times an exponential

y″ − y = te2t

Guess: degree 1 times e2t

Y = (At + B)e2t

Y′ = (2At + A + 2B)e2t

Y″ = (4At + 4A + 4B)e2t

Y″ − Y, divided by e2t

3At + 4A + 3B = t

t:  3A = 1,  A = 13;   1:  4A + 3B = 0,  B = −49

Y = (13t − 49)e2t

↳ an exponential times a cosine.

Example 3 — an exponential times a cosine

y″ − 3y′ − 4y = −8et cos 2t

Write Y = etu, with u = A cos 2t + B sin 2t

Y′ = et(u + u′),   Y″ = et(u + 2u′ + u″)

left side = et(u″ − u′ − 6u)  divide by et

u″ = −4u,  so  u″ − u′ − 6u = −10u − u′ = −8 cos 2t

Collect cos 2t and sin 2t

cos:  −10A − 2B = −8,   sin:  −10B + 2A = 0

A = 5B:  −52B = −8,  B = 213,  A = 1013

Y = et(1013 cos 2t + 213 sin 2t)

Factor out et first: then it is a cos/sin problem from Monday.

↳ Monday’s question: when the guess fails.

When the guess fails

y″ − 3y′ − 4y = 2e−t

Try Y = Ae−t

Y′ = −Ae−t,   Y″ = Ae−t

(A + 3A − 4A)e−t = 0  ≠ 2e−t

No value of A works.

Why: look at yc

(r − 4)(r + 1) = 0:  yc = c1e4t + c2e−t

e−t is already a solution of the homogeneous equation. The left side turns it into 0, so it can never produce 2e−t.

Fix: multiply the guess by t.  Y = Ate−t

The same idea as repeated roots: when ert is used up, the next one is tert.

↳ check that it works.

Example 4 — the fixed guess

y″ − 3y′ − 4y = 2e−t,   Y = Ate−t

Two derivatives, by the product rule

Y′ = A(1 − t)e−t

Y″ = A(t − 2)e−t

Put in, divide by e−t

A[(t − 2) − 3(1 − t) − 4t] = 2

The t terms cancel

t + 3t − 4t = 0;   −2 − 3 = −5

−5A = 2  ⇒  A = −25

Y = −25te−t

The t terms always cancel here: that is how you know the guess was right.

↳ why they cancel, for any equation.

Why multiplying by t works

ay″ + by′ + cy = eαt,  α a root of ar2 + br + c

Y = Ateαt

Y′ = A(1 + αt)eαt,   Y″ = A(2α + α2t)eαt

Put in, divide by eαt, collect

A[(aα2 + bα + c)t + (2aα + b)] = 1

aα2 + bα + c = 0  α is a root: the t terms cancel

What is left

A(2aα + b) = 1

Simple root: 2aα + b ≠ 0, so A exists. Example 4: 2(−1) − 3 = −5.

Double root: α = −b/(2a), so 2aα + b = 0 too. Then t is not enough: use t2.

The same two brackets as in §3.4.

↳ the rule, in one page.

The rule: compare with yc first

Always find yc before you guess Y

The rule

If a term of your guess is already in yc, multiply the guess by t.

If it is still in yc (a repeated root), multiply by t2.

With the characteristic roots

eαt:  α not a root → Aeαt;  simple root → Ateαt;  double → At2eαt

cos βt, sin βt:  iβ a root → t(A cos βt + B sin βt)

In plain words

If the guess is a homogeneous solution, the left side gives 0. Multiplying by t makes it different enough.

Multiply by t only as many times as needed: never more.

A constant g counts as e0t: check whether 0 is a root.

↳ a repeated root.

Example 5 — multiply by t2

y″ − 4y′ + 4y = e2t

yc first

(r − 2)2 = 0:  yc = (c1 + c2t)e2t

Ae2t is in yc. So is Ate2t. So use t2.

Y = At2e2t

Derivatives, divided by e2t

Y′: A(2t2 + 2t),   Y″: A(4t2 + 8t + 2)

A[(4t2 + 8t + 2) − 4(2t2 + 2t) + 4t2] = 2A = 1

Y = 12t2e2t

↳ the same problem with cos and sin.

Example 6 — cos 2t with roots ±2i

y″ + 4y = 3 cos 2t

yc first

r = ±2i:  yc = c1 cos 2t + c2 sin 2t

A cos 2t + B sin 2t is in yc, so multiply by t.

Y = t(A cos 2t + B sin 2t)

Put in (the t terms cancel)

Y″ + 4Y = −4A sin 2t + 4B cos 2t

4B = 3,  −4A = 0

Y = 34t sin 2t

The push has the same rhythm as the free motion. The size grows like t: resonance.

↳ the picture.

Example 6 — resonance

Y = 34t sin 2t oscillates with period π, like yc.

Dashed: ±34t. The curve stays between them and keeps growing.

Forcing at the natural frequency makes the oscillation grow without bound.

↳ everything together, with initial conditions.

True or false?

1.  For g = g1 + g2, we may find Y1 and Y2 separately and add.

2.  If e3t is in yc, the guess for g = e3t is Ate3t or At2e3t.

3.  For y″ + 9y = e3t, we must multiply by t.

The card — finding Y

Sums
