Friday, in one page

The three steps

  1. Split. Every y with dy, every x with dx.
  2. Integrate both sides. One constant.
  3. Solve for y — if you can, and if you are asked to.

If it will not split, it is not separable.

And two things were new

The answer is not always of the form y = something. An implicit answer is complete.

A solution has an interval. It is not always the whole line.

Today is entirely about those two.

↳ no new method today. Only a harder question about the answers.

Three from Friday — true or false?

1.  Every separable equation can be solved for y.

2.  An implicit answer is a complete answer.

3.  If the equation is defined everywhere, the solution is defined everywhere.

1.  false  you will see one in about five minutes

2.  true  unless the problem says “solve explicitly”

3.  false  and this one is worth a whole lecture

Number 3 is what today is about.

What the word “solution” actually means

We have used it all term. Here is the whole definition, in five lines.

A solution of y′ = f(x, y), y(x0) = y0, is

  1. a function y(x),
  2. on an open interval I that contains x0,
  3. differentiable at every point of I,
  4. with y′(x) = f(x, y(x)) at every point of I, and y(x0) = y0.

Three of those four lines are about the interval.

So a formula by itself is not a solution. A formula together with an interval is.

Line 3 is free whenever f is continuous

y′ = f(x, y(x)) is then continuous, so y is smooth

A corner can only appear where f itself jumps. The piecewise g in Lecture 4 — there we asked for continuity only.

The interval is part of the answer, not a footnote.

↳ nothing jumps today, so every solution here is smooth until it stops.

The problem I left you with

dydx = 4x − x34 + y3,   y(0) = 1

First question, before any work: is it separable?

top: only x  ·  bottom: only y

f(x) = 4x − x3,   g(y) = 14 + y3

Second question: is it linear?

No. y3 in a denominator is as far from linear as it gets.

Separable, not linear. Friday’s method, then.

↳ splitting it is the easy part. What comes after is today’s lesson.

Example 1 — split and integrate

dydx = 4x − x34 + y3,   y(0) = 1

Step 1  split

(4 + y3) dy = (4x − x3) dx

Step 2  integrate both sides

∫(4 + y3) dy = ∫(4x − x3) dx

4y + y44 = 2x2 − x44 + C

Initial condition, immediately

x = 0, y = 1:   4 + 14 = 0 + C   ⇒   C = 174

Multiply everything by 4

y4 + 16y = 8x2 − x4 + 17

Every coefficient is a whole number now. Clear the fractions whenever you can.

↳ that is the answer. It is implicit, and it is almost finished.

Now solve that for y

y4 + 16y = 8x2 − x4 + 17

It is a quartic in y. There is a formula for those. It is about a page long.

And it would give four branches, of which you would then have to choose one.

You are not going to solve this one for y.

So the implicit form is the answer. You write it down exactly as it stands.

But one thing is still missing

for which x is this actually a solution?

On Friday we read that off the formula. Here there is no formula to read.

↳ so we need a method that does not need one.

Example 1 — the solution stops at both ends

The direction field for this equation.

Look along the row near y = −1.6. Those strokes are almost vertical.

And the solution through y(0) = 1. Two humps, and then it stops.

Both ends stop at the same height, and the tangent there is vertical.

y = −3√4 ≈ −1.587

A solution has to be differentiable. A vertical tangent is exactly where it cannot continue.

−3.35 < x < 3.35  read from the picture

↳ but you will not have a picture on an exam. Next: the same answer by algebra.

Why the solution has to stop there

Look at the equation, not at the answer.

dydx = 4x − x34 + y3

The right-hand side is undefined when the bottom is zero.

4 + y3 = 0   ⇒   y3 = −4   ⇒   y = −3√4

A solution must have a derivative at every point of its interval.

At that one height, the equation cannot say what the derivative is.

So the solution stops the moment it reaches y = −3√4

↳ notice we found that from the equation alone, before solving anything.

Where does it reach that height?

y4 + 16y = 8x2 − x4 + 17,  with y = −3√4

Put that y into the answer

(−3√4)4 + 16(−3√4) = 8x2 − x4 + 17

The left side is just a number

44/3 − 16·41/3 = 41/3(4 − 16) = −12 3√4

≈ −19.05

So x has to satisfy

8x2 − x4 + 17 = −19.05

x4 − 8x2 − 36.05 = 0  a quadratic in x2

x2 = 8 + √64 + 144.22 = 11.21  the other root is negative, so it is out

−3.35 < x < 3.35

↳ and x = 0 is inside, which is what makes this the right piece.

Where does a solution stop? — three checks

  1. The x part. Where is f(x) undefined? 1/x, ln x, a square root
  2. The y part. Where does the denominator become zero? vertical tangent
  3. Infinity. Does y run off to ±∞ at a finite x?

Then take the piece that contains x0.

Each check hands you some bad x values. Mark them all on the axis, with x0.

The nearest bad point on each side of x0 is the one that matters. The rest never come into it.

The interval is open. The endpoints themselves are not included.

↳ the equation is fine everywhere. The solution is what stops.

Which check stops it? — call it out

1.  dydx = 1x y,   y(1) = 2

2.  dydx = −xy,   y(0) = 3

3.  dydx = 1 + y2,   y(0) = 0

4.  dydx = e−x − ex3 + 4y,   y(0) = 1

1.  checks 1 and 2  1/x on one side, y on the other

2.  check 2  y = 0 makes the slope infinite

3.  check 3  1 + y2 is never zero and never undefined

4.  check 2  3 + 4y = 0 somewhere

We are going to do all four.

Example 2 — two checks at once

dydx = 1x y,   y(1) = 2

Step 1  split

y dy = dxx

Step 2  integrate

y22 = ln|x| + C

Initial condition

x = 1, y = 2:   2 = ln 1 + C   ⇒   C = 2  ln 1 = 0

y2 = 2 ln|x| + 4  multiply by 2

Take the square root — and choose the sign

y = √2 ln x + 4

Positive, because y(1) = 2 is positive. The minus branch solves y(1) = −2.

And the bars are gone because x is going to stay positive — which is check 1.

↳ now run all three checks. They do not all give the same answer.

Example 2 — which one stops us first

y = √2 ln x + 4,  from dydx = 1/(x y), y(1) = 2

Check 1 — the x part

1/x needs x ≠ 0, and ln x needs x > 0

⇒  x > 0

Check 2 — the y part

1/(x y) is undefined when y = 0

y = 0  ⇔  2 ln x + 4 = 0  ⇔  x = e−2 ≈ 0.135

Check 3 — infinity

√2 ln x + 4 grows forever, but never in finite x. Nothing here.

Two bad points: x = 0 and x = e−2. The initial point is x = 1.

x > e−2

x = 0 never matters. e−2 stops us first, so 0 is never reached.

↳ the nearest bad point wins. That is the whole rule.

Example 3 — a circle, and one arc of it

dydx = −xy,   y(0) = 3

Step 1  split

y dy = −x dx

Step 2  integrate, then multiply by 2

y22 = −x22 + C   ⇒   y2 = −x2 + c

Initial condition

x = 0, y = 3:   9 = 0 + c   ⇒   c = 9

x2 + y2 = 9

A circle of radius 3. And a circle is not a function, so this cannot be the whole answer.

y = √9 − x2  upper half, because y(0) = 3 is positive

The lower half is a solution too — of y(0) = −3.

↳ one circle, two solutions, and neither of them is the circle.

Example 3 — the upper arc, and where it ends

The field for −x/y. It has nothing to say along the x-axis.

The strokes get steeper the closer you come to the x-axis.

The solution through y(0) = 3 is the top half of the circle.

It meets the x-axis at x = ±3, and there y = 0.

check 2:  −x/y is undefined when y = 0

−3 < x < 3

The tangent is vertical at both ends, so the solution cannot be continued past them.

↳ the circle is one curve. The solution is one arc of it.

What if you start on the bad set?

That solution ended where y = 0. So the line y = 0 is the bad set here.

dydx = −xy,   y(0) = 0

Now the initial point is on that line.

The equation cannot even say what y′(0) is, so nothing can start there.

No solution begins at that point.

And the opposite can happen too: sometimes more than one solution starts from the same point.

existence  ·  uniqueness  two separate questions

Today we assumed both, every time, without saying so.

↳ §2.4 says exactly when you are allowed to assume them.

Example 4 — an integral you know

dydx = 1 + y2,   y(0) = 0

Step 1  split

dy1 + y2 = dx

Step 2  integrate — you have met this one

∫dy1 + y2 = arctan y

arctan y = x + C

Initial condition

x = 0, y = 0:   arctan 0 = 0   ⇒   C = 0

y = tan x

Check 1: the x side is just 1, so nothing there.

Check 2: 1 + y2 is never zero, so nothing there either.

↳ so it has to be check 3 — and tan is the standard example of it.

Example 4 — infinity at a finite x

Every slope in this field is at least 1, and it grows very fast with |y|.

There is no flat stroke anywhere. The slope is never less than 1.

The solution through the origin is y = tan x.

It runs to +∞, and it gets there at x = π/2 — a finite x.

−π/2 < x < π/2

Nothing in 1 + y2 is undefined anywhere. The equation is perfectly well behaved.

↳ the solution still stops. That is check 3, and only the answer can show it to you.

Example 5 — a harder integral

dydx = e−x − ex3 + 4y,   y(0) = 1

Step 1  split

(3 + 4y) dy = (e−x − ex) dx

Step 2  integrate — watch both signs on the right

3y + 2y2 = −e−x − ex + C

Initial condition

x = 0, y = 1:   3 + 2 = −1 − 1 + C   ⇒   C = 7

2y2 + 3y = 7 − ex − e−x

This time it is only a quadratic in y

y = −3 ± √9 + 8(7 − ex − e−x)4

x = 0:  y = −3 ± 74 = 1 or −2.5  we need 1, so the plus sign

y = −3 + √65 − 8ex − 8e−x4

↳ and now the interval, which comes out exactly.

Example 5 — the interval comes out exactly

y = −3 + √65 − 8ex − 8e−x4

Check 2 says the trouble is at

3 + 4y = 0   ⇒   y = −34

And that is the same moment the square root reaches zero.

65 − 8ex − 8e−x = 0

Write u = ex

8u + 8u = 65   ⇒   8u2 − 65u + 8 = 0

u = 65 ± √4225 − 25616 = 65 ± 6316

u = 8  or  u = 18  both are clean

ex = 8 ⇒ x = ln 8  ·  ex = 18 ⇒ x = −ln 8

−ln 8 < x < ln 8  about −2.08 to 2.08

At both ends y = −3/4 exactly, which is where 3 + 4y dies.

↳ check 2 and the square root gave the same two points. They always will.

Where does each one live? — call it out

1.  y = ln(x − 2),   y(3) = 0

2.  y = 11 − x,   y(0) = 1

3.  y = √4 − x2,   y(0) = 2

4.  y = tan 2x,   y(0) = 0

1.  x > 2

2.  x < 1  not x ≠ 1 — the piece with 0 in it

3.  −2 < x < 2

4.  −π/4 < x < π/4  the 2 halves the interval

Number 2 is the one people get wrong.

Three checks

  1. Is the x part undefined somewhere?
  2. Does the y part become zero somewhere?
  3. Does y reach ±∞ at a finite x?

Take the open piece around x0.

Today, in four answers

1.  x > e−2  checks 1 and 2 — the nearer one wins

2.  −3 < x < 3  check 2

3.  −π/2 < x < π/2  check 3

↳ four equations, four different reasons to stop.

Where this is going

For a linear equation

y′ + p(t)y = g(t)

The interval is the largest one around t0 on which p and g are both continuous.

You can find it before you solve anything.

Linear: the interval comes from p and g.

For a nonlinear one

There is no such shortcut. You solve it first, and then run the three checks.

That is what we did four times today, and every time the answer was different.

Nonlinear: solve first, then find the interval.

↳ §2.4 is exactly this difference, stated as a theorem. Monday.

Where we are

§2.2 is finished.

separable  →  split, integrate, solve if you can  →  then say where it lives
