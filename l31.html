Today: §6.5

A force that acts in one instant: a hammer hits the spring.

We need a new function, the delta, and its transform.

The method stays the same.

A short, strong force

dε(t) = 1ε(u1(t) − u1 + ε(t))

dashed: ε = 1, height 1.

magenta: ε = 1/2, height 2.

teal: ε = 1/4, height 4.

area = width × height = ε · 1ε = 1

The area under a force is its impulse: the total push. Here it is always 1.

↳ its transform.

The transform, and the limit ε → 0

dε(t) = 1ε(uc(t) − uc + ε(t))

Transform: steps from Lecture 28

ℒ{dε(t)} = 1ε(e−css − e−(c + ε)ss)

= e−cs1 − e−εsεs

e−(c + ε)s = e−cse−εs: take e−cs out.

Let ε → 0

e−εs ≈ 1 − εs  for small ε

1 − e−εsεs ≈ 1 − (1 − εs)εs = εsεs = 1

ℒ{dε(t)} → e−cs

L’Hôpital in ε gives the same limit.

↳ the name for this limit.

The delta function

δ(t − c) = the limit of dε(t) as ε → 0

What it does

δ(t − c) = 0  for t ≠ c

∫0∞ δ(t − c) dt = 1  (c > 0)

It is not an ordinary function: zero everywhere except one point, but with area 1. It is a model of a push of size 1 at time c.

Its transform

ℒ{δ(t − c)} = e−cs

ℒ{δ(t)} = 1  c = 0

Compare: ℒ{uc(t)} = e−cs/s. The delta has no 1/s.

↳ a second way to see the transform.

Integrating against the delta

∫0∞ f(t) δ(t − c) dt = f(c)

Why

Use dε(t): it is 0 except on a short interval from c to c + ε.

there f(t) ≈ f(c), so  ∫0∞ f dε(t) dt ≈ f(c) · 1

As ε → 0, the ≈ becomes =.

The transform again

ℒ{δ(t − c)} = ∫0∞ e−st δ(t − c) dt

= e−sc  f(t) = e−st, evaluated at t = c

The same answer as the limit. The delta picks out the value at t = c.

↳ why the jump is exactly 1.

What jumps, and by how much

y″ + 4y = δ(t − c)

Integrate from just before c to just after

∫c−c+ y″ dt + 4∫c−c+ y dt = ∫c−c+ δ(t − c) dt

y′(c+) − y′(c−) + 0 = 1

y is continuous, so its integral over a tiny interval is 0.

The rule

second order:  y′ jumps by the size of the push

first order:  y jumps by the size of the push

Divide by the leading coefficient: for 2y″ + … = δ(t − c), y′ jumps by 1/2.

Step in g: y″ jumps.  Delta in g: y′ jumps.

↳ a hammer at the right moment.

Example 3 — a spring that is already moving

y″ + y = δ(t − π),   y(0) = 0,  y′(0) = 1

Transform, solve for Y

s2Y − 1 + Y = e−πs

Y = 1s2 + 1 + e−πs1s2 + 1

Invert each group

y = sin t + uπ(t) sin(t − π)

Simplify

sin(t − π) = −sin t

y = sin t − uπ(t) sin t :  sin t before π,  0 after

At t = π: y = 0 and y′ = cos π = −1. The push adds 1 to y′, so the speed becomes 0 at the rest position.
