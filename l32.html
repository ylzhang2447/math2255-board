Today: §6.6

Very often Y(s) is a product of two transforms.

Which function has a product of two transforms as its transform?

The answer: the convolution f ∗ g.

A product of transforms

y″ + y = g(t),   y(0) = 0,  y′(0) = 0

Transform

(s2 + 1)Y = G(s)

Y = 1s2 + 1 · G(s)

A product: the transform of sin t, times the transform of g. We do not know g yet, so we cannot use partial fractions.

Is the inverse of a product the product of the inverses?

try F(s) = G(s) = 1s:  F(s)G(s) = 1s2 → t

but f(t)g(t) = 1 · 1 = 1 ≠ t

ℒ−1{F(s)G(s)} ≠ f(t)g(t)

↳ the right operation.

The convolution of f and g

(f ∗ g)(t) = ∫0t f(t − τ) g(τ) dτ

How to read it

t is fixed while we integrate. The variable is τ, from 0 to t.

f is evaluated at t − τ, and g at τ. The two arguments always add up to t.

After the integral, the answer is a function of t.

Example: f(t) = t,  g(t) = t

(t ∗ t)(t) = ∫0t (t − τ) τ dτ

= ∫0t (tτ − τ2) dτ = t · t22 − t33

= t36

↳ a second example, and a check.

Example 1 — two exponentials

(e2t ∗ e−t)(t)

Write the integral

= ∫0t e2(t − τ) e−τ dτ

= e2t ∫0t e−2τ e−τ dτ = e2t ∫0t e−3τ dτ

e2t does not depend on τ, so it moves in front of the integral.

= e2t · 1 − e−3t3

= e2t − e−t3

Compare with partial fractions

1s − 2 · 1s + 1 = 13(1s − 2 − 1s + 1)

→ 13(e2t − e−t)

The same function. The inverse of the product of the transforms is the convolution. This is today’s theorem.

↳ some rules first.

Rules for convolution

f ∗ g = g ∗ f

Why: substitute u = t − τ

τ = 0 → u = t,  τ = t → u = 0,  dτ = −du

∫0t f(t − τ) g(τ) dτ = −∫t0 f(u) g(t − u) du

= ∫0t g(t − u) f(u) du = (g ∗ f)(t)

The minus sign flips the limits back.

Like multiplication

f ∗ (g + k) = f ∗ g + f ∗ k

(f ∗ g) ∗ k = f ∗ (g ∗ k),  f ∗ 0 = 0

Not like multiplication

(1 ∗ 1)(t) = ∫0t 1 dτ = t,  not 1

So 1 ∗ f is usually not f.

↳ the theorem.

The convolution theorem

ℒ{f ∗ g} = F(s)G(s)

Write the product of the transforms

F(s)G(s) = ∫0∞ e−sξf(ξ) dξ · ∫0∞ e−sτg(τ) dτ

= ∫0∞ g(τ) [∫0∞ e−s(ξ + τ)f(ξ) dξ] dτ

Inner integral: put ξ = t − τ (τ fixed)

∫0∞ e−s(ξ + τ)f(ξ) dξ = ∫τ∞ e−stf(t − τ) dt

Put it back

F(s)G(s) = ∫0∞ ∫τ∞ e−stf(t − τ) g(τ) dt dτ

Swap the order of integration

= ∫0∞ e−st [∫0t f(t − τ) g(τ) dτ] dt

= ℒ{f ∗ g}

↳ why we may swap.

Swapping the order

Both double integrals cover the same region: 0 ≤ τ ≤ t, the shaded triangle.

before: fix τ, then t from τ to ∞

after: fix t, then τ from 0 to t

Only the order changes, so the value stays the same.

ℒ−1{F(s)G(s)} = (f ∗ g)(t)

Initial value problems with any forcing g

ay″ + by′ + cy = g(t),   y(0) = y0,  y′(0) = y0′

Transform

(as2 + bs + c)Y − (asy0 + ay0′ + by0) = G(s)

Y = asy0 + ay0′ + by0as2 + bs + c + G(s)as2 + bs + c

Name the parts

H(s) = 1as2 + bs + c,  h(t) = ℒ−1{H(s)}

Invert

y = φ(t) + (h ∗ g)(t) = φ(t) + ∫0t h(t − τ) g(τ) dτ

φ(t): the free part. It comes from the initial values, as if g = 0.

h ∗ g: the forced part. It comes from g, with zero initial values.

If g = δ(t), then G(s) = 1 and Y = H. So h is the response to one push at t = 0, as on Friday.

↳ why h ∗ g gives the forced part.

Why the forced part is h ∗ g

zero initial values:  y = ∫0t h(t − τ) g(τ) dτ

One push

A push of size 1 at time 0 gives the response h(t).

A push of size 1 at time τ gives the shifted response h(t − τ) for t > τ.

push of size g(τ) dτ at time τ  →  g(τ) dτ · h(t − τ)

Many pushes

Think of g on [0, t] as many small pushes, one at each time τ.

The equation is linear, so the responses add.

adding them:  ∫0t h(t − τ) g(τ) dτ

h: the answer to one push.  g: the pushes.
