One root is not enough

ay″ + by′ + cy = 0,   b2 − 4ac = 0

The quadratic formula

r = −b ± 02a = −b2a  one root, twice

y1 = ert is a solution

y = c1ert has only one constant. It cannot match y(0) and y′(0) both.

What we need

A second solution y2 with W(y1, y2) ≠ 0.

So y2 must not be a constant multiple of ert.

Idea (d’Alembert): try y2 = v(t)ert, with a function v.

↳ find v. Every line on the board.

Finding the second solution

y = v(t)ert,   r = −b/(2a)

Two derivatives, by the product rule

y′ = (v′ + rv)ert

y″ = (v″ + 2rv′ + r2v)ert

Put them into ay″ + by′ + cy, and collect

ert[av″ + (2ar + b)v′ + (ar2 + br + c)v] = 0

Two brackets are zero

ar2 + br + c = 0  r is a root

2ar + b = 0  r = −b/(2a)

What is left

av″ = 0  ⇒  v = c1 + c2t

y = c1ert + c2tert

↳ the second solution is tert.

The recipe

ay″ + by′ + cy = 0,   b2 − 4ac = 0

1. Characteristic equation; check b2 − 4ac = 0.

2. The root r = −b/(2a).

3. y = (c1 + c2t)ert.

4. Initial conditions: solve for c1, c2.

W(ert, tert) = e2rt ≠ 0  a fundamental set

The derivative

y′ = r(c1 + c2t)ert + c2ert

At t = 0

y(0) = c1

y′(0) = rc1 + c2

↳ three examples.

Example 1 — a general solution

y″ + 4y′ + 4y = 0

Roots

r2 + 4r + 4 = (r + 2)2 = 0:  r = −2, twice

y = (c1 + c2t)e−2t

Check y2 = te−2t

y2′ = (1 − 2t)e−2t,   y2″ = (−4 + 4t)e−2t

(−4 + 4t) + 4(1 − 2t) + 4t = 0  ✓

As t → ∞, te−2t → 0: the exponential wins over t.

↳ now with initial conditions.

Example 2 — an initial value problem

y″ − 4y′ + 4y = 0,   y(0) = 12,   y′(0) = −3

Roots

(r − 2)2 = 0:  r = 2

y = (c1 + c2t)e2t

Initial conditions

y(0) = c1 = 12

y′(0) = rc1 + c2 = 2(12) + c2 = −3  ⇒  c2 = −27

y = (12 − 27t)e2t

The usual mistake: y′(0) = c2, forgetting rc1.

↳ one where the long run depends on y′(0).

Example 3 — the slope decides the long run

y″ − y′ + 14y = 0,   y(0) = 2

Roots

(r − ½)2 = 0:  r = ½

y = (c1 + c2t)et/2,   c1 = 2

y′(0) = ½(2) + c2 = 1 + c2

y′(0) = ⅓

c2 = −⅔:  y = (2 − ⅔t)et/2 → −∞

y′(0) = 2

c2 = 1:  y = (2 + t)et/2 → +∞

The sign of c2 decides: the term c2t wins in the end.

↳ the picture.

Example 3 — the picture

teal: y′(0) = ⅓. It rises, turns, and falls below zero at t = 3.

magenta: y′(0) = 2. It grows.

dashed: y′(0) = 1, so c2 = 0 and y = 2et/2.

y′(0) = 1 is the border between the two behaviors.

Reduction of order — for any equation

y″ + p(t)y′ + q(t)y = 0,   y1 is known

Try y = vy1

y′ = v′y1 + vy1′

y″ = v″y1 + 2v′y1′ + vy1″

Put in, and collect

v(y1″ + py1′ + qy1) + y1v″ + (2y1′ + py1)v′ = 0

The first bracket is zero: y1 is a solution

y1v″ + (2y1′ + py1)v′ = 0

No v, only v′ and v″. Let w = v′: a first-order equation for w.

Solve for w, integrate to get v, then y2 = vy1.

The repeated-root derivation was this, with y1 = ert.

↳ Friday’s equation from §3.2.

Example 4 — reduction of order

2t2y″ + 3ty′ − y = 0,  t > 0,   y1 = t−1

y = vt−1

y′ = v′t−1 − vt−2

y″ = v″t−1 − 2v′t−2 + 2vt−3

Put in: the v terms cancel

(2tv″ − 4v′ + 4v/t) + (3v′ − 3v/t) − v/t

= 2tv″ − v′ = 0

w = v′: separable

True or false?

1.  If b2 − 4ac = 0, then y = c1ert is the general solution.

2.  te−4t → 0 as t → ∞.

3.  The solution of y″ + 2y′ + y = 0, y(0) = 0, y′(0) = 1 is te−t.

4.  Reduction of order only works for constant coefficients.

5.  For a repeated root, y′(0) = c2.

1.  false  one constant; we need tert too

2.  true  the exponential wins

3.  true  r = −1, c1 = 0, c2 = 1

4.  false  Example 4

5.  false  rc1 + c2

↳ number 5 is the most common mistake on this topic.
