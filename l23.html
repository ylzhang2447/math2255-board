Midterm 1 first.

Midterm 1, Problem 1

ty′ − y = t2et,   y(1) = e + 1,   t > 0

Standard form first: divide by t

y′ − 1ty = tet,   p = −1t

μ = e−∫1/t dt = e−ln t = 1t

(yt)′ = et  ⇒  yt = et + c  ⇒  y = tet + ct

y(1) = e + c = e + 1:  c = 1

y = tet + t

The most common mistake

μ = t instead of 1/t: the minus sign in p = −1/t was lost.

Also common: not dividing by t first, which gives the wrong p; and c not multiplied by t at the end.

Check: μ′ must equal p·μ. With μ = t: μ′ = 1, but pμ = −1.

↳ Problem 2.

Midterm 1, Problem 2

dydx = 3x2 + 32y,   y(0) = 2

a. Separate and integrate

2y dy = (3x2 + 3) dx  ⇒  y2 = x3 + 3x + c,  c = 4

y = +√x3 + 3x + 4  + because y(0) = 2 > 0

b. Where is it valid?

x3 + 3x + 4 = (x + 1)(x2 − x + 4) > 0

x2 − x + 4 > 0 always  (1 − 16 < 0)  ⇒  −1 < x < ∞

The most common mistakes

(b) without factoring: a few test values do not show the sign everywhere.

(a) the + sign chosen with no reason.

A closed interval: at x = −1, y = 0 and the equation divides by zero.

The hint was there for a reason: use the root −1 to factor.

↳ Problem 3.

Midterm 1, Problem 3

(3xy + 2y2) + (x2 + 2xy)y′ = 0,   y(1) = 1

a.  My = 3x + 4y ≠ Nx = 2x + 2y:  not exact

b.  My − NxN = x + 2yx(x + 2y) = 1x  ⇒  μ = eln x = x

c.  ψ = ∫(3x2y + 2xy2)dx = x3y + x2y2 + h(y),  h′ = 0

x3y + x2y2 = 2

The most common mistakes

Using the ratio 1/x itself as μ. The ratio goes into e∫…; μ = x.

Writing ψy = N as the final answer. The answer is ψ = c.

Forgetting the initial condition: c = 1 + 1 = 2.

The last line of an exact equation is always ψ(x, y) = c, with c found.

↳ Problem 4.

Midterm 1, Problem 4

dydt = y2(y − 3)(y + 2)

a.  equilibria y = −2, 0, 3

b.  signs from below:  +  |  −  |  −  |  +  test points −3, −1, 1, 4

c.  −2 asymptotically stable,  0 semistable,  3 unstable

d.  y(0) = −1 → −2;   y(0) = 1 → 0

The most common mistake: part (d)

From y(0) = 1 the arrow points down, toward 0. The solution approaches 0 and stops there; it cannot cross an equilibrium.

So the limit is 0, not −2. A semistable point still catches solutions from one side.

Read the limit from the arrow next to the starting value, and stop at the first equilibrium.

Six common mistakes

from homework and from class

1. Guessing before finding yc. You cannot know whether to multiply by t.

2. Only sin, or only cos. A y′ term turns one into the other.

3. Missing powers: At2 for t2. Derivatives create the lower powers.

4. Multiplying by t when it is not needed. The letters will not fit.

5. Multiplying every piece of a sum by t. Only the piece that is in yc.

6. Initial conditions on yc alone. Y(0) is usually not 0.

Always check: put Y back into the equation.

↳ three examples, done carefully.

Example 1 — a product, and a root

y″ − 2y′ − 3y = −3te−t

yc and the guess

(r − 3)(r + 1):  yc = c1e3t + c2e−t

−1 is a simple root, so the usual (At + B)e−t is multiplied by t:

Y = pe−t,   p = At2 + Bt

Factor out e−t (Wednesday’s trick)

Y′ = (p′ − p)e−t,   Y″ = (p″ − 2p′ + p)e−t

Left side, divided by e−t

(p″ − 2p′ + p) − 2(p′ − p) − 3p = p″ − 4p′

2A − 4(2At + B) = −3t

t:  −8A = −3,  A = 38;   1:  2A − 4B = 0,  B = 316

Y = (38t2 + 316t)e−t

↳ the p terms dropped out: that is the sign the t was right.

Example 2 — a sum where one piece needs t

y″ + 2y′ = 3 + 4 sin 2t

yc

r(r + 2) = 0:  r = 0, −2;  yc = c1 + c2e−2t

Piece 3: a constant, and 0 is a root

Y1 = At:  0 + 2A = 3,  A = 32

Piece 4 sin 2t: ±2i are not roots

Y2 = B cos 2t + C sin 2t

Y2″ + 2Y2′ = (−4B + 4C) cos 2t + (−4C − 4B) sin 2t

−4B + 4C = 0,  −4C − 4B = 4  ⇒  B = C = −12

Y = 32t − 12 cos 2t − 12 sin 2t

Only the constant collided with yc. The sine piece kept its usual guess.

↳ a mistake to find.

Find the mistake

y″ + 9y = e3t

A student’s work

“There is a 9 and a 3, so 3 is special. Multiply by t.”

Y = Ate3t:  Y″ + 9Y = A(6 + 18t)e3t

A(6 + 18t) = 1 for every t?  impossible

The mistake

The roots are ±3i, not 3. e3t is not in yc, so no t is needed.

Y = Ae3t:  9A + 9A = 1

Y = 118e3t

In plain words: an extra t leaves a t term that nothing can cancel.

2.  For y″ + y = cos t + t, both pieces need t.
