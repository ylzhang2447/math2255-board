Today

In applications a forcing is often switched on or off at a given time.

For example, a voltage of 5 is turned on at t = 2 and turned off at t = 6.

We need one formula for such a function: the unit step.

The unit step function

uc(t) = 0,   t < c
1,   t ≥ c   c ≥ 0

It is 0 before the time c, and 1 from c on: it jumps up by 1 at t = c.

The graph shows u2(t).

The value at the single point t = c does not change any integral, so it does not matter for the transform.

↳ how to switch something off.

Switching on, switching off, and a window

Multiply f(t) by a step to switch it

Three rules

on at c:  uc(t)f(t)

off at c:  (1 − uc(t))f(t)

on for a ≤ t < b:  (ua(t) − ub(t))f(t)

Why the window works

t < a:  0 − 0 = 0

a ≤ t < b:  1 − 0 = 1

t ≥ b:  1 − 1 = 0

The voltage example: 5(u2(t) − u6(t))

Example 4 — a piece that is not constant

f(t) = t,   0 ≤ t < 2
2,   t ≥ 2

The same rule: at t = 2 add (new − old)

f(t) = t + (2 − t)u2(t)

2 − t = −(t − 2)

f(t) = t − (t − 2)u2(t)

We wrote the second part with t − 2, the time since the switch. This form is the one the transform needs.

↳ a common mistake, as a picture.

Two different functions

teal: u2(t)t2. It jumps from 0 to 4 at t = 2.

dashed: u2(t)(t − 2)2. It starts from 0 at t = 2.

Both are switched on at t = 2, but after the switch they are different functions.

So they have different transforms.

↳ now the transform of a step.

The transform of a step

ℒ{uc(t)} = ∫0∞e−stuc(t) dt

The step is 0 before c

= ∫c∞e−st dt = limA→∞ ∫cAe−st dt

= limA→∞ [−e−sts]cA
= limA→∞ (e−css − e−sAs)

ℒ{uc(t)} = e−css,   s > 0

With c = 0 this is ℒ{1} = 1s.

A switch at time c gives a factor e−cs.

↳ a delayed function that is not constant.

The shift theorem in t

ℒ{uc(t)f(t − c)} = e−csF(s)

Why

ℒ{uc(t)f(t − c)} = ∫c∞e−stf(t − c) dt

let τ = t − c:  = ∫0∞e−s(τ + c)f(τ) dτ

= e−cs∫0∞e−sτf(τ) dτ = e−csF(s)

A delay by c in t ↔ a factor e−cs in s

Compare the shift rule from Lecture 25: a factor eat in t ↔ a shift s → s − a in s.

F is the transform of f itself, not of the delayed function.
