Finding μ when it depends on x only

(μM)y = (μN)x  the test, for the multiplied equation

Product rule on both sides

μyM + μMy = μxN + μNx

Guess: μ depends on x only

μy = 0,   μx = μ′(x)

μMy = μ′N + μNx

μ′N = μ(My − Nx)

μ′μ = My − NxN  the right side must contain no y

Integrate, as in §2.1

ddx ln|μ| = μ′μ

∫ddx ln|μ| dx = ∫My − NxN dx

ln|μ| = ∫My − NxN dx  no constant: one μ is enough

μ = ±e∫…dx  the ± removes the bars; take +

μ(x) = e∫(My − Nx)/N dx

↳ if the ratio still has a y in it, there is no μ(x). Try the other one, later today.

The recipe

  1. Read M, N and test. Equal? Then Wednesday’s four steps. Done.
  2. Not equal: compute (My − Nx)/N. Only x left? Then μ(x) = e∫…dx.
  3. Otherwise: compute (Nx − My)/M. Only y left? Then μ(y). After the first practice.
  4. Multiply the whole equation by μ, and test again.
  5. Four steps on the new equation: ψ = c.

Checks that cost nothing

After step 4 the test must pass. If it does not, the μ or the algebra is wrong.

The answer ψ = c also solves the original equation. Differentiate it and compare.

If neither ratio works, stop. Other integrating factors exist, but not in this course.

Example 2

y′ = e2x + y − 1

0  one side:  (e2x + y − 1) − y′ = 0

M = e2x + y − 1,   N = −1  test: 1 ≠ 0

My − NxN = 1 − 0−1 = −1  ⇒  μ = e−x

(ex + ye−x − e−x) − e−x y′ = 0  both partials e−x ✓

ψ = ex − ye−x + e−x + h(y)

ψy = −e−x + h′ = −e−x  ⇒  h = 0

Finding μ when it depends on y only

μyM + μMy = μxN + μNx  the same first line as before

Guess: μ depends on y only

μx = 0,   μy = μ′(y)

μ′M + μMy = μNx

μ′M = μ(Nx − My)

μ′μ = Nx − MyM  the right side must contain no x

ln|μ| = ∫Nx − MyM dy  same steps as before

μ(y) = e∫(Nx − My)/M dy

Side by side

μ(x):  My − NxN  must be only x

μ(y):  Nx − MyM  must be only y

The top is the same difference with the sign flipped. The bottom is the other function.

Do not memorize both. Remember the first line, and guess which variable μ needs.

M = 1,   N = x/y − sin y;   My = 0,  Nx = 1/y

Try x

Try y

Nx − MyM = 1/y1 = 1y  ⇒  μ = eln|y|  ⇒  μ = y

Example 4 — a μ with two pieces

y + (2xy − e−2y) y′ = 0

M = y,   N = 2xy − e−2y;   My = 1,  Nx = 2y

x-ratio:  (1 − 2y)/N  has y

y-ratio:  2y − 1y = 2 − 1y  ✓

∫(2 − 1/y) dy = 2y − ln|y|

μ = e2y − ln|y| = e2y|y|  ⇒  μ = e2yy

e2y + (2xe2y − 1/y) y′ = 0  test: 2e2y both ✓

ψ = xe2y + h(y)

ψy = 2xe2y + h′ = 2xe2y − 1/y  ⇒  h = −ln|y|

xe2y − ln|y| = c

Also y = 0 solves the original equation, and μ is undefined there. Next page.

Two warnings

1  μ is not unique

Any constant times μ works. We always drop the ± and the constant.

Some equations have completely different integrating factors. Example 1 also has μ = 1/(xy(2x + y)).

Every choice gives the same solution curves. Pick the easy one.

2  Look where μ is 0 or undefined

Multiplying by μ is only safe where μ ≠ 0 and μ exists.

Example 4:  y ≡ 0:  0 + (0 − 1)·0 = 0  ✓

y = 0 is a solution that xe2y − ln|y| = c does not contain.

Check the lines where μ is 0 or undefined, as with separable equations.
