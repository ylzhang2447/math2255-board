The inverse transform

If ℒ{f} = F(s), we write  f = ℒ−1{F}

Why this makes sense

Theorem. Let f and g be piecewise continuous and of exponential order. If ℒ{f} = ℒ{g} for all large s, then f(t) = g(t) at every t where both are continuous.

So a transform comes from only one continuous function. We may call it the inverse transform.

The inverse is linear too

ℒ−1{c1F + c2G} = c1ℒ−1{F} + c2ℒ−1{G}

Because ℒ{c1f + c2g} = c1F + c2G, read from right to left.

↳ how to compute it: read the table backwards.

Reading the table backwards

1s − a → eat,   n!sn+1 → tn,   bs2 + b2 → sin bt,   ss2 + b2 → cos bt

What to look at

1. The denominator tells you the function: s − a, a power of s, or s2 + b2.

2. Then make the numerator match the table, using linearity to move constants out.

The two places students lose a constant

1s3 = 12·2!s3 → 12t2

1s2 + 9 = 13·3s2 + 9 → 13 sin 3t

The shift rule, backwards

ℒ−1{F(s − a)} = eatf(t),   where f = ℒ−1{F}

How to use it

1. Every s appears as s − a. Read a.

2. Find the inverse with s in place of s − a.

3. Multiply by eat.

1(s − 2)3:  a = 2,  1s3 → 12t2,  so → 12t2e2t

s + 1(s + 1)2 + 4:  a = −1,  ss2 + 4 → cos 2t,  so → e−tcos 2t

The numerator must also be written with s + 1, not with s.

↳ but our Y from Wednesday is not in the table.

Why partial fractions

Y(s) = s − 1(s − 2)(s + 1)   is not in the table

Add two simple fractions

1/3s − 2 + 2/3s + 1 = 13(s + 1) + 23(s − 2)(s − 2)(s + 1)

= s − 1(s − 2)(s + 1)  ✓

Now go the other way

Each simple fraction is in the table: 1s − 2 → e2t and 1s + 1 → e−t.

Partial fractions is the reverse of adding fractions: we split Y into pieces that are in the table.

↳ how to find the numbers 1/3 and 2/3.

Partial fractions: distinct linear factors

s − 1(s − 2)(s + 1) = As − 2 + Bs + 1

Multiply both sides by (s − 2)(s + 1)

s − 1 = A(s + 1) + B(s − 2)

This holds for every s. So we may choose s to remove one unknown at a time.

s = 2:   1 = 3A,   A = 13

s = −1:   −2 = −3B,   B = 23

Plug in the roots of the denominator. Each root makes one term zero.

↳ now we can finish Example 3.

Y(s) = s − 1(s − 2)(s + 1) = 1/3s − 2 + 2/3s + 1

Invert each piece

y(t) = 13e2t + 23e−t

Check

y(0) = 13 + 23 = 1 ✓,   y′(0) = 23 − 23 = 0 ✓

The exponents 2 and −1 are the roots of the characteristic polynomial s2 − s − 2, the same as in chapter 3.

We never solved for c1 and c2: the initial values were inside Y from the start.

↳ the method in four steps.

The method

differential equation for y(t)  →  algebra for Y(s)  →  y(t)

1. Transform both sides. Use ℒ{y′} and ℒ{y″} with the initial values.

2. Solve for Y(s).

3. Split Y by partial fractions.

4. Invert each piece with the table.

You can always check: y(0) and y′(0).

Why use it, when chapter 3 works?

The initial values enter at step 1, so there are no constants to solve for at the end.

Next week the forcing will switch on and off at given times. Undetermined coefficients cannot handle that; the transform can.

Example 3 — a forcing, three linear factors

y″ − y = 3e2t,   y(0) = 0,   y′(0) = 0

1. Transform

s2Y − Y = 3s − 2

2. Solve for Y

Y(s) = 3(s − 2)(s − 1)(s + 1)
= As − 2 + Bs − 1 + Cs + 1

3. Multiply out, plug in the roots

3 = A(s − 1)(s + 1) + B(s − 2)(s + 1)
 + C(s − 2)(s − 1)

s = 2:  3 = 3A,  A = 1

s = 1:  3 = −2B,  B = −32

s = −1:  3 = 6C,  C = 12

4. Invert

y(t) = e2t − 32et + 12e−t

Check: y(0) = 1 − 32 + 12 = 0 ✓,  y′(0) = 2 − 32 − 12 = 0 ✓

↳ a factor that does not split.

Partial fractions: a quadratic factor

1(s − 1)(s2 + 1) = As − 1 + Bs + Cs2 + 1

Why Bs + C

s2 + 1 has no real roots, so it does not split. Over it we need a numerator of degree one: Bs gives cosine and C gives sine.

Multiply by (s − 1)(s2 + 1)

1 = A(s2 + 1) + (Bs + C)(s − 1)

s = 1:   1 = 2A,   A = 12

Only one real root. For the rest, compare coefficients:

s2:  0 = A + B,   B = −12

s0:  1 = A − C,   C = −12

Check with s1: 0 = −B + C = 12 − 12 ✓

↳ this finishes Wednesday’s Example 4.

Example 6 — a constant forcing
