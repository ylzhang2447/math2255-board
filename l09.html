Three claims from Monday — true or false?

2.  If the theorem is silent, the problem has no solution.

1.  false  y′ = y2, y(0) = 1 ends at t = 1

Three questions for today

  1. How long does the solution live? Monday said “some interval”. Today: it depends on where you start.
  2. How many solutions can there be when the theorem is silent? Two on Monday. Today: infinitely many.
  3. What does “general solution” mean? One formula, one constant. Does it contain every solution?

And the pattern of the answers

For a linear equation, every answer is the comfortable one.

For a nonlinear one, every answer has an exception.

Same equation, different starting point, different answer.

Difference 1 — does the interval depend on the start?

Linear  y′ = 2y

y = y0e2t   lives on −∞ < t < ∞

The interval came from p and g. y0 never entered.

This is always true for linear equations. The interval is fixed before the starting value is even chosen.

Nonlinear  y′ = y2

y = y01 − y0t   lives up to t = 1/y0

The interval depends on y0. It is not in the equation at all.

That is what “some interval” in Monday’s theorem was hiding. The h can depend on the starting point.

Linear: the interval is a property of the equation.  Nonlinear: of the solution.

Example 2 — the theorem is silent. How many solutions?

dydt = y1/3,   y(0) = 0

The theorem

f = y1/3  continuous everywhere

∂f∂y = 13y−2/3 = 13y2/3  undefined at y = 0

(0, 0) is on the bad set  ⇒  silent

Solution 1: the obvious one

y = 0 for all t:  0′ = 0 = 01/3  ✓

Solution 2: separate, for y ≠ 0

y−1/3 dy = dt   ⇒   32y2/3 = t + c

y(0) = 0:  c = 0   ⇒   y2/3 = 2t3  needs t ≥ 0

y = ±(2t/3)3/2,   t ≥ 0

check:  y′ = 32(2t/3)1/2 · 23 = (2t/3)1/2 = y1/3  ✓

Three solutions already: 0, +, and −.

Example 2 — a solution may wait at zero, then leave

dydt = y1/3,   y(0) = 0

Pick any moment t0 > 0

χ(t) = 0  for 0 ≤ t < t0

χ(t) = (2(t − t0)/3)3/2  for t ≥ t0

Zero until t0, then the same curve as before, shifted right.

Is it a solution? Check the join

from the left:  χ′ = 0

from the right:  χ′ = (2(t − t0)/3)1/2 → 0

both sides:  χ′ = χ1/3  ✓  and χ(0) = 0  ✓

One solution for every t0. Infinitely many.

Plus the minus version of each. Plus y = 0 itself.

Monday’s tank was this, run backward: empty now, and it could have emptied at any time.

This one runs forward: at zero now, and it may leave zero at any time. Or never.

why: ∂f∂y breaks at y = 0, and we start there

↳ start anywhere else, and there is exactly one. Same equation, different point, different answer.

Look at what happened

From (0, −1) and from (0, 3) we reached the same implicit equation.

(y − 1)2 = x3 + 2x2 + 2x + 4  one curve, two branches

Lower branch: the solution from (0, −1). Upper branch: this one. They meet at (−2, 1), on the bad line, and both stop there.

One implicit equation can hold two different solutions.

Example 3 — the bad line, and what happens at it

The dashed line is y = 1. Every stroke near it is vertical.

From (0, −1): one curve. It runs left and stops at x = −2, vertical, on the line.

From (0, 3): the upper branch of the same curve. It meets the first one at (−2, 1), on the line.

From (0, 1): two curves. One climbs, one falls. Both leave the line vertically.

Off the line the theorem holds and nothing touches. All the meeting happens on y = 1.

The bad set is where solutions start, stop, and meet.

Difference 3 — what “general solution” promises

Linear

y = 1μ∫μg dt + cμ

Monday’s proof: every solution must have this form. One constant, and it contains all of them.

general solution = every solution

Nonlinear

y′ = y2:  y = −1t + c  misses y = 0

y′ = y1/3:  32y2/3 = t + c  misses y = 0 and every χ

Where did they go? We divided by y. Dividing assumes y ≠ 0, and the solutions with y = 0 in them were thrown away on that line.

Nonlinear: a one-parameter family. Not “the general solution”.

↳ the habit: whenever you divide by something with y in it, ask what you lost.

Difference 4 — explicit or implicit

Linear

y = 1μ∫μg dt + cμ

Always y = something. Explicit, every time. The only thing that can fail is the integral, and even then you can write it as an integral.

Nonlinear

y4 + 16y = 8x2 − x4 + 17  last Wednesday

Usually the best you get is F(x, y) = 0. Implicit. Sometimes it can be solved for y; often not.

It is still a complete answer. To get a number out of it you solve F = 0 numerically, one x at a time.

Linear: a formula for y.  Nonlinear: an equation that y satisfies.

↳ four differences. One card.

What a complete answer looks like

  1. Name the type. Linear or separable. That decides the method.
  2. Say what the theorem promises before you solve. Linear: the interval from p, g. Nonlinear: does it apply at (t0, y0)?
  3. Solve, every line. Write μ and the one-derivative line, or the split and both integrals.
  4. Choose the sign from the initial condition when you take a root.
  5. State the interval. Open. Around t0.

Two things that lose points

A formula with no interval. Half an answer.

μ built from g instead of p. Everything after it is wrong.

The card — linear against nonlinear

Linear  y′ + p y = g

check:  p, g continuous

you get:  one solution on all of I

interval:  from the equation, before solving

depends on y0?  no

when silent:  none or one

general solution:  contains every solution

form:  explicit, y = …

Nonlinear  y′ = f(t, y)

check:  f, ∂f∂y continuous

you get:  one solution on some interval

interval:  solve, then the three checks

depends on y0?  yes

when silent:  none, one, two, or infinitely many

family:  may miss solutions (the ones you divided by)

form:  usually implicit, F(t, y) = 0

Three more — true or false?

1.  y′ = y2 has a solution that exists for every t.

2.  For y′ = y1/3, every initial value problem has infinitely many solutions.

3.  A linear equation can have an answer that is only implicit.

1.  true  y = 0. Exactly one such solution.

2.  false  only when y0 = 0. Off the axis, exactly one.

3.  false  the formula always gives y explicitly

Number 2 is the one to remember: it is the point, not the equation.
