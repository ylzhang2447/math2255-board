Back to solving. So far you can solve two families by hand: linear and separable.

Today a third: exact equations. A two-line test tells you when you have one, and a four-step method solves it.

The idea comes from one line of multivariable calculus.

↳ HW3 is now due next Monday, Sep 28. Quiz 1 scores will be out this week.

Three claims — true or false?

1.  dydx = x2 + y22xy is separable.

2.  Every first-order equation can be written as M(x, y) + N(x, y) y′ = 0.

3.  If y(x) satisfies ψ(x, y) = c, then ψx + ψy y′ = 0.

1.  false  the top does not split into f(x)g(y)

2.  true  move everything to one side; N may be 1

3.  true  the chain rule from Calculus 3

Number 3 is the whole method. Number 1 is why we need it.

The general form, and why the old methods fail

M(x, y) + N(x, y) y′ = 0  also written M dx + N dy = 0

A small one

2x + y2 + 2xy y′ = 0  M = 2x + y2, N = 2xy

Linear? No: y2, and y multiplies y′.

Separable? Solve for y′: −(2x + y2)/(2xy). The top is a sum, so no.

And yet it has a one-line solution

x2 + xy2 = c

Check by differentiating both sides in x, remembering y depends on x:

2x + y2 + 2xy y′ = 0  ✓

↳ the equation is the derivative of something. Finding that something is today.

The words

Exact

M + N y′ = 0 is exact if there is a function ψ(x, y) with

ψx = M  and  ψy = N

ψ is called a potential function. Same word as in physics: M and N are its two slopes.

Differential form

M dx + N dy = 0

The same equation, written without choosing which variable is the function. Divide by dx to get back M + N y′ = 0.

In this form, M is whatever multiplies dx, and N is whatever multiplies dy. Read them off before anything else.

↳ the small example: ψ = x2 + xy2. Now why that solves it.

Why ψ(x, y) = c is the solution

ψx = M,   ψy = N

The chain rule for a function of two variables

if y = y(x), then  ddxψ(x, y(x)) = ψx + ψy dydx

= M + N y′  by the two conditions

So the equation says

ddxψ(x, y(x)) = 0

ψ(x, y(x)) = c  a function with zero derivative is constant

Every solution lies on a level curve ψ(x, y) = c.

The small example, from this side

ψ = x2 + xy2

ψx = 2x + y2 = M  ✓   ψy = 2xy = N  ✓

so  x2 + xy2 = c  is the solution

Implicit, like most separable answers. Solve for y only if asked.

↳ two questions remain: when does such a ψ exist, and how do you find it?

The test — when does ψ exist?

M + N y′ = 0  is exact  ⇔  My = Nx  on a rectangle where M, N, My, Nx are continuous

Why it is necessary

suppose ψx = M and ψy = N

then  My = ψxy  and  Nx = ψyx

mixed partials are equal  ⇒  My = Nx

So if the two derivatives differ, no ψ can exist. The method is dead before it starts.

The book proves the converse too: on a rectangle, equal partials guarantee a ψ. The construction is the method.

The test on the small example

M = 2x + y2:  My = 2y

N = 2xy:  Nx = 2y

equal  ⇒  exact

Two partial derivatives. Compare them. Nothing else.

↳ how to write the test: differentiate M in y, and N in x. The cross pattern.

The recipe

  1. Read M and N. N is what multiplies y′ (or dy). Everything else, on the same side, is M.
  2. Test: My = Nx? If not, stop.
  3. Integrate M in x: ψ = ∫M dx + h(y). The constant may depend on y.
  4. Match N: differentiate ψ in y, set equal to N, solve for h′(y). Integrate to get h.

ψ(x, y) = c  is the answer. Then the initial condition.

Two checks that cost nothing

In step 4, h′(y) must contain no x. If an x survives, the equation is not exact or the algebra is wrong.

At the end, differentiate ψ = c implicitly. You must get the equation back.

You may also start from N: ψ = ∫N dy + g(x), then match M. Pick the easier integral.

↳ the small example first, all four steps.

Example 0 — the small one, all four steps

2x + y2 + 2xy y′ = 0

1  read

M = 2x + y2,   N = 2xy

2  test

My = 2y,   Nx = 2y  ✓

3  integrate M in x

ψ = ∫(2x + y2) dx = x2 + xy2 + h(y)  y is a constant here

4  match N

ψy = 2xy + h′(y)  =  N = 2xy

h′(y) = 0  no x in it: good  ⇒  h = 0

x2 + xy2 = c

check:  2x + y2 + 2xy y′ = 0  ✓

↳ now one where h is not zero.

Example 1

(y cos x + 2xey) + (sin x + x2ey − 1) y′ = 0

1  read

M = y cos x + 2xey,   N = sin x + x2ey − 1

2  test

My = cos x + 2xey

Nx = cos x + 2xey  ✓  exact

3  integrate M in x

ψ = y sin x + x2ey + h(y)

4  match N

ψy = sin x + x2ey + h′(y)

= sin x + x2ey − 1  ⇒  h′(y) = −1

h(y) = −y  no constant needed; it joins c

y sin x + x2ey − y = c

Cannot be solved for y. Implicit is the finished answer.

↳ the −1 in N had no x to come from; that is exactly what h is for.

Example 2 — with an initial condition

2xy − 9x2 + (2y + x2 + 1) y′ = 0,   y(0) = −3

1, 2  read and test

M = 2xy − 9x2,   N = 2y + x2 + 1

My = 2x,   Nx = 2x  ✓

3  integrate M in x

ψ = x2y − 3x3 + h(y)

4  match N

ψy = x2 + h′(y) = 2y + x2 + 1

h′(y) = 2y + 1  ⇒  h = y2 + y

x2y − 3x3 + y2 + y = c

Initial condition

x = 0, y = −3:  0 − 0 + 9 − 3 = c  ⇒  c = 6

Solve for y — a quadratic in y

y2 + (x2 + 1)y − (3x3 + 6) = 0

y = −(x2 + 1) ± √x4 + 12x3 + 2x2 + 252

x = 0:  (−1 ± 5)/2 = −3 needs the minus sign

↳ the radicand is zero near x ≈ −1.40; the solution lives on x > −1.40.

Example 2 — the solution curve, and two neighbors

The direction field of y′ = −M/N. Not autonomous: the strokes change along a row.

Three level curves of ψ: c = 3, 6, 10. The middle one passes through (0, −3).

Each runs to the left until its square root dies, and stops there vertically. For c = 6 that is x ≈ −1.40.

vertical where N = 2y + x2 + 1 = 0  check 2: N in the denominator

Solutions are contour lines of ψ. The equation is its gradient.

↳ the picture behind the word “potential”. Now one that fails the test.

Example 3 — when the test fails

(3xy + y2) + (x2 + xy) y′ = 0

1, 2  read and test

M = 3xy + y2,   N = x2 + xy

My = 3x + 2y,   Nx = 2x + y

Not equal. Not exact. Stop here.

What happens if you do not stop

ψ = ∫M dx = 32x2y + xy2 + h(y)

ψy = 32x2 + 2xy + h′(y)  =  x2 + xy

h′(y) = −12x2 − xy  contains x

Impossible: h depends on y only. The method breaks at step 4, exactly where the test said it would.

The equation still has solutions. This method just cannot find them.

Three families, three tests

linear:  y′ + p(x)y = g(x)  y and y′ to the first power, never multiplied together

separable:  y′ = f(x) g(y)  the right side splits into a product

exact:  M + N y′ = 0 with My = Nx

Run all three tests on a new equation. Use whichever passes. If two pass, the answers agree.

One equation, three ways

y + x y′ = 0

linear:  μ = x,  (xy)′ = 0,  xy = c

separable:  dy/y = −dx/x,  ln|y| = −ln|x| + c,  xy = C

exact:  ψ = xy,  xy = c

↳ the exact route is the shortest here. Often it is. One more example.

The card — exact equations

Form and test

M(x, y) + N(x, y) y′ = 0  or M dx + N dy = 0

exact  ⇔  My = Nx

Why

ψx = M, ψy = N  ⇒  ddxψ(x, y(x)) = 0  ⇒  ψ = c

Four steps

  1. read M, N
  2. test My = Nx
  3. ψ = ∫M dx + h(y)  or ∫N dy + g(x)
  4. ψy = N → h′(y), no x allowed → h

answer ψ(x, y) = c  ·  check by implicit differentiation
