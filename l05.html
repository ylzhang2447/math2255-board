Two kinds, two methods

Linear — §2.1, Monday and Wednesday

y′ + p(t)y = g(t)

y appears once, to the first power, with nothing done to it.

μ = e∫p dt  four steps, always the same four

Separable — §2.2, today

dydx = f(x) g(y)

The right-hand side splits into an x part times a y part.

g(y) is allowed to be anything — squared, downstairs, inside a log

Neither family contains the other. Some equations are both. Plenty are neither.

Today’s equations do not have to be linear.

The method — you have already used it once

On the first Friday you solved this one.

dydt = y − 3

dyy − 3 = dt

ln|y − 3| = t + C

That was the whole method. Today it gets a name.

  1. Split. Every y with dy on one side, every x with dx on the other.
  2. Integrate both sides. One constant is enough.
  3. Solve for y — if you can, and if you are asked to.

If it will not split, it is not separable.

↳ then go back to Wednesday’s four steps instead.

Why you are allowed to move dx across

dydx is not a fraction. So that step needs a reason.

Write the equation this way

N(y) dydx = M(x)

Let H be any antiderivative of N

H′(y) = N(y)

Now the chain rule, read forwards

ddxH(y(x)) = H′(y) dydx = N(y) dydx

So the left side of the equation already is one derivative in x.

ddxH(y(x)) = M(x)

H(y) = ∫M(x) dx + C  integrate both sides in x

Splitting is the chain rule, run backwards.

↳ same idea as μ on Monday: get one side to be a single derivative.

Example 1 — the first non-linear one

dydx = x2y2  not linear: y is downstairs, and squared

Step 1  split

y2 dy = x2 dx  multiply by y2, then by dx

Step 2  integrate both sides

∫y2 dy = ∫x2 dx

y33 = x33 + C  one C, not one on each side

Step 3  solve for y

y3 = x3 + 3C  multiply everything by 3

y3 = x3 + c  3C is still just a constant — call it c

y = (x3 + c)1/3

↳ the integrating factor cannot even start here. There is no standard form to write.

Example 2 — with an initial condition

dydt = t y2,   y(0) = 1

Step 1  split

dyy2 = t dt

Step 2  integrate

∫y−2 dy = ∫t dt

−1y = t22 + C  watch that minus sign

Put the initial condition in now, before solving for y

t = 0, y = 1:   −1 = 0 + C   ⇒   C = −1

Step 3  now solve for y

−1y = t22 − 1   ⇒   1y = 2 − t22

y = 22 − t2

↳ on Monday the constant went in last. For these it is easier first.

Example 2 — the solution runs into a wall

There is nothing wrong with the equation anywhere here.

But the solution through y(0) = 1 climbs, and does not come back.

y = 22 − t2  the denominator hits zero at t = √2 ≈ 1.41

−√2 < t < √2

t = 0 has to be inside. That is what picks this piece and not another.

Start lower and the wall moves: y(0) = 0.4 gives y = 2/(5 − t2), which lasts until √5.

↳ same equation. The interval is decided by the initial point.

Example 3 — when you cannot solve for y

dydx = 2x1 + 2y,   y(2) = 0

Step 1  split

(1 + 2y) dy = 2x dx

Step 2  integrate

y + y2 = x2 + C

Initial condition

x = 2, y = 0:   0 = 4 + C   ⇒   C = −4

y2 + y = x2 − 4

You could finish with the quadratic formula. Usually you are not asked to.

This form has a name

an implicit solution  no y = … anywhere in it

An implicit solution is a complete answer.

↳ if the problem does not say “solve explicitly”, you may stop on that line.

Your turn — problems 1 to 3

1.  dydx = xy

2.  dydx = 3x2y  this one is separable and linear

3.  dydx = 2x3y2,   y(0) = 2

8 minutes.  Work with the person next to you. Do 1 first.

On number 2, do it whichever way you like — then try the other way if you have time.

Problems 1 to 3 — answers

1.

y dy = x dx   ⇒   y22 = x22 + C

y2 = x2 + c  implicit is fine here

2.  by separating

dyy = 3x2 dx   ⇒   ln|y| = x3 + C

y = c ex3

2.  the other way

y′ − 3x2y = 0,   μ = e−x3

(μy)′ = 0   ⇒   μy = c   ⇒   y = c ex3

3.

3y2 dy = 2x dx   ⇒   y3 = x2 + C

y(0) = 2:  8 = 0 + C   ⇒   y = (x2 + 8)1/3

Same answer both ways on 2. Use whichever is shorter for you.

About that absolute value

Problem 2 gave you ln|y|, and the answer had no bars in it. Here is why.

ln|y| = x3 + C

Exponentiate both sides

|y| = ex3 + C = eC ex3

Drop the bars, keep both signs

y = ±eC ex3

eC is some positive number. The ± then makes it any non-zero number.

y = c ex3  c ≠ 0

And c = 0 gives y = 0, which solves y′ = 3x2y as well — check it.

So we let c be any constant, and the bars are gone for good.

↳ here the constant solution came back on its own. It does not always. Wait for Example 6.

Example 4 — it does not look separable

dydx = ex − y

Nothing splits. There is no product of an x part and a y part — yet.

The whole problem is one exponent law

ex − y = ex e−y

Step 1  now it splits

ey dy = ex dx  1/e−y = ey

Step 2  integrate — both sides are the same integral

ey = ex + c

Step 3  solve for y

y = ln(ex + c)

and this needs ex + c > 0. For c ≥ 0 that is every x.

↳ when an equation looks impossible, try breaking an exponent or a log apart first.

Example 5 — the one from the book

dydx = 3x2 + 4x + 22(y − 1),   y(0) = −1

Step 1  split

2(y − 1) dy = (3x2 + 4x + 2) dx

Step 2  integrate

y2 − 2y = x3 + 2x2 + 2x + C

Initial condition, straight away

x = 0, y = −1:   1 + 2 = 0 + C   ⇒   C = 3

y2 − 2y = x3 + 2x2 + 2x + 3

That is already a correct answer. But this time the problem does ask for y.

↳ and that is where the interesting part is. Next page.

Example 5 — solving for y, and choosing a branch

y2 − 2y = x3 + 2x2 + 2x + 3,  with y(0) = −1

Complete the square on the left

y2 − 2y + 1 = x3 + 2x2 + 2x + 4  add 1 to both sides

(y − 1)2 = x3 + 2x2 + 2x + 4

Square root — and a square root has two signs

y = 1 ± √x3 + 2x2 + 2x + 4

Only one of the two fits the initial condition

x = 0:   y = 1 ± √4 = 1 ± 2  that is 3 or −1, and we need −1

y = 1 − √x3 + 2x2 + 2x + 4

The plus sign is a perfectly good solution — of a different initial value problem.

↳ the initial condition does two jobs here: it fixes C, and it picks the sign.

And where does that answer live?

A square root needs its inside to be positive.

x3 + 2x2 + 2x + 4 > 0

Group it in pairs

x2(x + 2) + 2(x + 2)

= (x + 2)(x2 + 2)

x2 + 2 is positive for every x. So only the first factor decides.

x + 2 > 0

x > −2  and x = 0 is inside, as it must be

At x = −2 the answer is y = 1, which is exactly where the original denominator 2(y − 1) dies.

↳ twice today now: the equation is fine, and the solution is the thing that stops.

Example 6 — a solution the method throws away

dydx = y2

Step 1  split

dyy2 = dx  notice what we just divided by

Step 2  integrate

−1y = x + C

Step 3  solve for y

y = −1x + C

Now put y = 0 into the original equation.

left side 0,  right side 02 = 0  it is a solution

But no value of C makes −1/(x + C) equal to zero.

Whenever you divide, check whether that thing is itself a solution.

↳ constant solutions like this are called equilibrium solutions. §2.5 is about them.

Example 6 — the missing one is the flat one

The slope is y2, so it is never negative. Everything here goes up, or stays put.

Along y = 0 the slope is exactly zero, all the way across.

Above it, every curve runs off to infinity in finite x.

Below it, every curve creeps up toward zero and never arrives.

y = −1/(x + C) draws every curve here except the flat one.

↳ that is the one we divided away in step 1.

Which method? — call it out

1.  y′ + 2y = et

2.  dydx = x y

3.  dydx = x + y

4.  dydx = y2

5.  dydx = cos(x + y)

1.  linear  et will not factor out a y part

2.  both  x times y — and y is first power

3.  linear  x + y is a sum, not a product

4.  separable  f = 1, g = y2. Not first power, so not linear.

5.  neither  and we will not be solving that one

You decide this from the shape, before doing any work.

Your turn — problems 4 and 5

4.  dydx = x + 1y − 2,   y(0) = 4  leave it implicit

5.  dydt = 2ty + y t2  factor the bottom before you do anything

4 minutes.  Just these two.

Problems 4 and 5 — answers

4.

(y − 2) dy = (x + 1) dx

(y − 2)22 = x22 + x + C

(y − 2)2 = x2 + 2x + c  multiply everything by 2

y(0) = 4:   22 = 0 + c   ⇒   c = 4

(y − 2)2 = x2 + 2x + 4

5.  the bottom factors

y + y t2 = y(1 + t2)   ⇒   y dy = 2t1 + t2dt

y22 = ln(1 + t2) + C  top is the derivative of the bottom

y2 = 2 ln(1 + t2) + c

↳ no absolute value needed — 1 + t2 is always positive.

Three places people lose marks

  1. Two constants. One C is enough — the second one just moves across and joins it.
  2. Forcing an explicit y. Implicit is complete, unless the problem says “solve explicitly”.
  3. Dividing without looking. The thing you divided by may itself be a solution.

And one question worth asking every single time

Where does this answer live?

Today it came up three times: at √2, at x = −2, and along y = 0.

↳ §2.4 answers it properly, later in this chapter.
