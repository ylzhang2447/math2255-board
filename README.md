# Math 2255 — Lecture Boards

Interactive lecture boards for Math 2255 (Differential Equations), Autumn 2026.

Open on an iPad, then **Share → Add to Home Screen** and launch from the icon
for full screen with no browser chrome.

- Arrow buttons, swipe, or tap the left/right edge to step through
- Only the Apple Pencil draws; palm and fingers do not leave marks
- `HD` / `Fast` toggles the drawing resolution
