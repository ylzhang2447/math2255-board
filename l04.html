Monday, in four steps

  1. Standard form. Read p from it.
  2. μ = e∫p dt
  3. (μy)′ = μg
  4. Integrate, then divide every term by μ.

y = 1μ(∫μg dt + c)

And μ came out two different ways

p = a number  ⇒  μ = ekt

p = kt  ⇒  μ = tk  because e and ln cancel

Today: three more kinds of p, and integrals that fight back.

↳ steps 1, 3, 4 never change. Only step 2 gets harder.

Example 1

y′ + 2t y = t  already standard form, p = 2t

1  build μ

μ = e∫2t dt = et2

2  multiply every term by μ

et2y′ + 2t et2y = t et2

3  the left side is one derivative

(et2y)′ = t et2

4  integrate, then divide by μ

the right side needs u = t2, du = 2t dt

et2y = ∫t et2 dt = 12et2 + c

y = ½et2 + cet2 = 12 + cet2

y = 12 + c e−t2

↳ e to the t squared, not e to the two t. Look at the integral, not at p.

Example 2 — the integral fights back

y′ + y = t  p is a number again, but g is not

1  build μ

μ = e∫1 dt = et

2  multiply every term by μ

ety′ + ety = t et

3  the left side is one derivative

(ety)′ = t et

4  integrate, then divide by μ

by parts: u = t, dv = etdt  ⇒  uv − ∫v du

ety = ∫t et dt = t et − ∫et dt = (t − 1)et + c

y = (t − 1)et + cet = (t − 1) + cet

y = t − 1 + c e−t

↳ no equilibrium here. The answer grows, because g grows.

Problem 3 — answer

y′ + 3ty = 1t3

μ

∫3tdt = 3 ln t = ln t3

μ = eln t3 = t3

(t3y)′ = t3 · 1t3 = 1

t3y = ∫1 dt = t + c

↳ μ was chosen so the right side cancels. That is what it is for.

Example 3 — a minus inside the log

t y′ − y = t2  for t > 0

0  divide by t

y′ − 1ty = t  so p = −1/t

1  build μ

μ = e∫(−1/t) dt = e−ln t = eln t−1 = 1t

2  multiply every term by μ

1ty′ − 1t2y = 1t · t

3  the left side is one derivative

(yt)′ = 1

4  integrate, then divide by μ

yt = ∫1 dt = t + c

y = t (t + c)

y = t2 + c t

↳ a minus in the exponent flips it over. It does not put a minus sign in front.

Example 4 — and where the answer lives

t y′ + 2y = t2,   y(1) = 2

0  divide by t

y′ + 2ty = t  this needs t ≠ 0

1  build μ

μ = e∫(2/t) dt = eln t2 = t2

2  multiply every term by μ

t2y′ + 2t y = t2 · t

3  the left side is one derivative

(t2y)′ = t3

4  integrate, then divide by μ

t2y = ∫t3 dt = t44 + c

y = t4/4 + ct2 = t24 + ct2

y = t24 + 74t2,   t > 0

y(1) = 14 + c = 2   ⇒   c = 74

t = 1 is on the positive side, and 1/t2 dies at 0

↳ the equation is fine at t = 0. The answer is not.

Example 5 — which start stays bounded?

y′ − 2y = 4  find y(0) so the solution does not blow up

1  build μ

μ = e∫−2 dt = e−2t

2  multiply every term by μ

e−2ty′ − 2e−2ty = 4e−2t

3  the left side is one derivative

(e−2ty)′ = 4e−2t

4  integrate, then divide by μ

e−2ty = −2e−2t + c

y = −2e−2t + ce−2t

y = −2 + c e2t

c > 0 ⇒ y → +∞  ·  c < 0 ⇒ y → −∞

c = 0 ⇒ y = −2 always  the equilibrium

only y(0) = −2 stays bounded

↳ the exponent is positive, so c decides everything.

Example 5 — the dividing line

y′ − 2y = 4  solutions run away from −2

Start above −2 and you go up forever. Start below and you go down forever.

Only y(0) = −2 stays. One number out of infinitely many.

Example 6 — the forcing switches off

y′ + 2y = g(t),   y(0) = 0,  where g = 1 on 0 ≤ t ≤ 1, and g = 0 for t > 1

first piece: 0 ≤ t ≤ 1, so g = 1

μ = e∫2 dt = e2t

(e2ty)′ = 1 · e2t

e2ty = 12e2t + c1

y = ½e2t + c1e2t = 12 + c1 e−2t

y(0) = 12 + c1 = 0  ⇒  c1 = −12

y = 12(1 − e−2t)

second piece: t > 1, so g = 0

same μ, and now (e2ty)′ = 0 · e2t = 0

e2ty = c2  ⇒  y = c2 e−2t

the two pieces must agree at t = 1

y(1) = 12(1 − e−2)  from the first piece

c2e−2 = 12(1 − e−2)  ⇒  c2 = 12(e2 − 1)

y = 12(e2 − 1) e−2t,  t > 1

↳ the first piece hands its last value to the second piece.

Example 6 — one solution, two formulas

The direction field itself changes at t = 1.

Before that the solution climbs toward 12. After that it decays to zero.

y(1) = 12(1 − e−2) ≈ 0.43  both formulas give this value

The graph is continuous. We forced that when we matched the two pieces.

The slope is not continuous. There is a corner at t = 1.

y′ = g − 2y  y is continuous, so Δy′ = Δg = 1

Solve on each piece, then match.

↳ Chapter 6 does this in one pass, with no pieces.

What μ turned out to be

p = k   ⇒   μ = ekt  an exponential

p = kt   ⇒   μ = tk  e and ln cancel

p = −kt   ⇒   μ = 1tk  the minus flips it over

p = 2t   ⇒   μ = et2  not e2t

μ is never a guess. Do the integral, then look.

Two things worth remembering

A minus in the exponent gives a reciprocal, not a minus sign.

Sometimes the left side is already a product rule. Look before you divide.

If g is given in pieces, run the four steps once per piece, then match at the joint.

↳ the four steps themselves did not change once today. Only p, g and the integrals did.
