Two kinds, two methods

Linear — §2.1, this week

y′ + p(t)y = g(t)  integrating factor

Separable — §2.2, today

dydx = f(x) g(y)  split and integrate

Neither one contains the other. Some equations are both. Some are neither.

Today’s equations do not have to be linear.

The method

Two Fridays ago you solved this one.

dydt = y − 3   →   dyy − 3 = dt   →   ln|y − 3| = t + C

That is the whole method. It has a name now.

  1. Get every y on one side with dy, every x on the other with dx.
  2. Integrate both sides. One constant is enough.
  3. Solve for y — if you can. Sometimes you have to leave it implicit.

If it will not split, it is not separable. Try §2.1 instead.

Example 1

dydx = x2y2  not linear: y is downstairs and squared

Step 1  split

y2 dy = x2 dx

Step 2  integrate

y33 = x33 + C

Step 3  solve for y

y3 = x3 + c  3C is still just a constant, so call it c

y = (x3 + c)1/3

↳ try the integrating factor on this and you get nowhere. It is not linear.

Example 2 — with an initial condition

dydt = t y2,  y(0) = 1

dyy2 = t dt   ⇒   −1y = t22 + C

Put the initial condition in now, before solving for y

t = 0, y = 1:   −1 = 0 + C   ⇒   C = −1

−1y = t22 − 1   ⇒   y = 22 − t2

Where does this actually live?

−√2 < t < √2  the denominator dies at ±√2, and t = 0 must be inside

Example 3 — when you cannot solve for y

dydx = 2x1 + 2y,  y(2) = 0

(1 + 2y) dy = 2x dx   ⇒   y + y2 = x2 + C

x = 2, y = 0:   0 = 4 + C   ⇒   C = −4

y2 + y = x2 − 4

You could use the quadratic formula here. Usually you are not asked to.

This is an implicit solution, and it is a complete answer.

Your turn — problems 1 to 4

1.  dydx = xy

2.  dydx = 3x2y  this one is separable and linear

3.  dydx = 2x3y2,   y(0) = 2

4.  dydx = ex − y  it does split — look again

12 minutes.  Work with the person next to you. Do 1 first.

Problems 1 and 2 — answers

1.  y dy = x dx   ⇒   y22 = x22 + C   ⇒   y2 = x2 + c

2.  dyy = 3x2 dx   ⇒   ln|y| = x3 + C   ⇒   y = c ex3

2 the other way

y′ − 3x2y = 0,  μ = e−x3   ⇒   (μy)′ = 0   ⇒   y = c ex3

Same answer. When both methods apply, use whichever is shorter.

Problems 3 and 4 — answers

3.  3y2 dy = 2x dx   ⇒   y3 = x2 + C

   y(0) = 2:  8 = 0 + C   ⇒   y = (x2 + 8)1/3

4 — the exponent law is the whole trick

ex − y = ex e−y   ⇒   ey dy = ex dx

ey = ex + c

y = ln(ex + c)

↳ nothing splits until you use ea−b = ea e−b. Always look for that.

Your turn — problems 5 to 7

5.  dydx = x + 1y − 2,   y(0) = 4  leave it implicit

6.  dydt = 2ty + yt2  factor the bottom first

7.  dydx = y2,   y(0) = 1  then say where it lives

10 minutes.  Same pairs.

Problems 5 to 7 — answers

5.  (y − 2) dy = (x + 1) dx   ⇒   (y − 2)2 = x2 + 2x + 4

6.  bottom = y(1 + t2)   ⇒   y dy = 2t1 + t2dt

   y22 = ln(1 + t2) + C   ⇒   y2 = 2 ln(1 + t2) + c

7.  −1y = x − 1   ⇒   y = 11 − x

and it only lives on  x < 1

↳ the equation looks fine at x = 1. The solution is what blows up.
