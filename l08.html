Three claims — true or false?

1.  Every initial value problem has a solution.

2.  If it has a solution, it has only one.

3.  For a linear equation you can find the interval before you solve.

1.  false  Wednesday: y′ = −x/y, y(0) = 0 has none

2.  false  Friday: the empty tank has two

3.  true  and today you see why

Two false, one true. All three are §2.4.

Two questions about every initial value problem

  1. Existence. Is there a solution at all?
  2. Uniqueness. Is there only one?

You have already met both answers being no.

y′ = −x/y,  y(0) = 0  no solution

dhdt = −0.2√h,  h(30) = 0  two solutions

Why anyone asks

Before you solve: an hour of algebra on a problem with no answer is an hour lost.

After you solve: if there is only one, you may stop looking.

Linear: yes and yes, always.  Nonlinear: it depends.

↳ and the difference is a theorem, not a feeling.

The theorem for linear equations

y′ + p(t)y = g(t),   y(t0) = y0

If

p and g are both continuous on an open interval I,

and t0 is inside I,

then

there is a solution,

there is only one,

and it lives on all of I.

Read it as a contract

You check two functions for continuity. That is the entire hypothesis.

In return you get a solution defined on the whole interval, not just near t0.

The solution can break only where p or g breaks.

↳ Wednesday’s preview, with the word “theorem” on it. Next: why it is true.

Why it is true — the integrating factor is the proof

y′ + p(t)y = g(t)  p, g continuous on I

1  build μ — this needs p continuous

μ = e∫p dt > 0  a continuous p has an antiderivative

2  multiply every term

μy′ + μp y = μg

3  the left side is one derivative

(μy)′ = μg  because μ′ = μp

4  integrate — this needs g continuous

∫(μy)′ dt = ∫μg dt

μy = ∫μg dt + c  c is born here

5  divide by μ:  y = 1μ∫μg dt + cμ

6  initial condition:  y(t0) = y0  ⇒  exactly one c

Exists on all of I: the formula.  Only one: the c.

↳ the hypothesis was used exactly twice: at ∫p and at ∫μg.

The recipe — the interval before the solution

  1. Standard form. Divide so that y′ stands alone.
  2. Write down p and g.
  3. Mark every t where p or g is undefined or jumps.
  4. Take the largest open interval around t0 with no mark inside it.

interval = the piece around t0 where p and g are both continuous

And you can always check

Solve it. The answer breaks exactly where p or g breaks, and nowhere else.

If your answer breaks somewhere else, the algebra is wrong. The theorem is a free error check.

Nothing here needs the solution. Four steps, no integral.

↳ the first example is one you have already solved. Now watch the interval come out first.

Example 3 — and one we can check

y′ + (tan t) y = sin t,   y(π) = 0

Already standard form

p = tan t,   g = sin t

Where do they break?

tan t:  undefined at ±π2, ±3π2, …

sin t:  nowhere

Take the piece around t0 = π

π2 < t < 3π2

You can always check — solve it

μ = e−ln|cos t| = 1|cos t|  so use μ = sec t

sec t y′ + sec t tan t y = sec t sin t

(sec t y)′ = tan t   ⇒   sec t y = −ln|cos t| + c

y = −cos t ln|cos t| + c cos t  divide by sec t

y(π) = 0:  0 + c(−1) = 0  ⇒  c = 0

y = −cos t · ln|cos t|

↳ undefined where cos t = 0: π/2 and 3π/2. Exactly the two ends.

Call out the interval

1.  y′ + 1t − 2y = et,   y(0) = 1

2.  (t + 1) y′ + y = ln t,   y(2) = 0

3.  y′ + tt2 − 4y = 1,   y(−1) = 5

4.  (cos t) y′ + y = t,   y(0) = 1

1.  t < 2  one mark, at 2; t0 is on the left

2.  t > 0  divide first: g = ln t/(t + 1). The mark at −1 never matters

3.  −2 < t < 2  marks at ±2

4.  −π/2 < t < π/2  divide by cos t: p = 1/cos t

↳ four intervals, no integrals. Number 2 is the one people miss: divide first.

The theorem for nonlinear equations

y′ = f(t, y),   y(t0) = y0

If

f and ∂f∂y are both continuous on a rectangle α < t < β,  γ < y < δ,

and (t0, y0) is inside the rectangle,

then

there is exactly one solution,

on some interval t0 − h < t < t0 + h.

Three things got weaker

1.  two functions to check, and one is a derivative

2.  a rectangle, not an interval: y matters too

3.  “some interval” — h is not given

The linear case is inside this one:

f = g − p y,   ∂f∂y = −p

↳ continuous f and ∂f∂y is exactly continuous g and p.

The recipe — nonlinear

  1. Write f(t, y) with y′ alone on the left.
  2. Compute ∂f∂y. t is a constant while you do it.
  3. Find the bad set: every (t, y) where f or ∂f∂y is undefined.
  4. Is (t0, y0) off the bad set? Yes: exactly one solution near t0. On it: the theorem says nothing.

And you can always check

Solve it, and run Wednesday’s three checks.

The theorem says a solution exists near t0. The three checks say how far it goes.

Theorem first, checks second. Never the other way.

↳ the first example is Wednesday’s Example 2. We already know how far it goes.

empty the whole time  the axis

Forward in time the picture is fine: an empty tank stays empty.

Backward, the curves merge. Once they touch h = 0 they cannot be told apart.

Curves may only meet on the bad set.

↳ and off the bad set, never. That is the next page.

Solutions never cross

Suppose two solution curves crossed at a point (t1, y1).

Then both solve y′ = f(t, y), y(t1) = y1. Two solutions of one initial value problem.

Where the theorem holds, that is impossible.

Off the bad set, solution curves never touch.

Linear equations have no bad set inside I. Their curves never touch at all.

What that buys you

An equilibrium solution is a wall. Start below it, stay below it forever.

tank:  Q = 25 is a solution, so Q(0) = 10 never reaches 25

y′ = y2:  y = 0 is a solution, so y(0) = 1 can never come down to 0

The draining tank did touch h = 0. Allowed, because h = 0 is the bad set.

↳ you have used this since week two, every time a curve stayed between two others.

Can we use the theorem to guarantee a unique solution?

1.  y′ = t2 + y2,   y(0) = 1

2.  y′ = √y,   y(0) = 0

3.  y′ = √y,   y(0) = 4

4.  y′ = t + yt − y,   y(1) = 1

1.  yes  ∂f∂y = 2y, continuous everywhere

2.  no  ∂f∂y = 1/(2√y), undefined at y = 0, and we start there

3.  yes  same f, but (0, 4) is off the bad set

4.  no  f is undefined on the line y = t, and (1, 1) is on it

↳ No = the theorem does not apply. A unique solution may still exist.
