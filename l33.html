§3.2 — the Wronskian and fundamental sets

Example: y″ − y′ − 2y = 0,  y1 = e2t, y2 = e−t

W = y1y2y1′y2′ = y1y2′ − y2y1′

= e2t(−e−t) − e−t(2e2t) = −3et

−3et ≠ 0  ⇒  a fundamental set:  y = c1e2t + c2e−t

Abel: p = −1,  W = c e−∫p dt = c et  ✓

Example: (t − 4)y″ + 3y′ + ty = cos t,  y(1) = 2, y′(1) = 0

divide by t − 4:  p = 3t − 4,  q = tt − 4,  g = cos tt − 4

all continuous except at t = 4

unique solution on −∞ < t < 4

↳ the interval must contain the initial point t = 1.

§3.4 — repeated roots

b2 − 4ac = 0:  one root r = −b2a

y = (c1 + c2t)ert

y(0) = c1,   y′(0) = rc1 + c2

Why tert: reduction of order, y = v(t)ert gives v″ = 0.

Example: y″ + 6y′ + 9y = 0,  y(0) = 1, y′(0) = −1

r2 + 6r + 9 = (r + 3)2  ⇒  r = −3, double

y = (c1 + c2t)e−3t,   c1 = 1

y′ = c2e−3t − 3(c1 + c2t)e−3t

y′(0) = c2 − 3c1 = −1  ⇒  c2 = 2

y = (1 + 2t)e−3t

↳ the product rule gives two terms in y′; do not drop rc1.

§3.5 — undetermined coefficients

1  yc first

2  guess from g: eat → Aeat;  polynomial of degree n → full polynomial of degree n;  sin or cos → both

3  a term of the guess is in yc → multiply by t (by t2 for a double root)

4  plug in, match coefficients

5  y = yc + Y; initial values last

Example: y″ + 4y′ + 3y = 10 sin t

r = −1, −3:  yc = c1e−t + c2e−3t

Y = A cos t + B sin t,  Y″ = −Y

(2A + 4B) cos t + (2B − 4A) sin t = 10 sin t

2A + 4B = 0,  2B − 4A = 10  ⇒  B = 1, A = −2

y = c1e−t + c2e−3t − 2 cos t + sin t

↳ next: only the form of Y, out loud.

§6.1 — the definition

ℒ{f(t)} = ∫0∞ e−stf(t) dt

∫0∞ = limA→∞ ∫0A:  an improper integral

It converges when the limit exists and is finite. Only some s work.

linear: ℒ{af + bg} = aF + bG

Example: ℒ{e3t} from the definition

∫0∞ e−ste3t dt = limA→∞ ∫0A e−(s − 3)t dt

= limA→∞ 1 − e−(s − 3)As − 3

s > 3: e−(s − 3)A → 0;  s ≤ 3: diverges

ℒ{e3t} = 1s − 3,   s > 3

↳ write the limit, and say for which s.

§6.2 — solving an initial value problem

ℒ{y′} = sY − y(0)

ℒ{y″} = s2Y − sy(0) − y′(0)

Both initial values go in at the start. There is no c1, c2 to find later.

Example: y″ + 2y′ + 5y = 0,  y(0) = 2, y′(0) = 0

(s2Y − 2s) + 2(sY − 2) + 5Y = 0

(s2 + 2s + 5)Y = 2s + 4

Y = 2s + 4(s + 1)2 + 4  complete the square

2s + 4 = 2(s + 1) + 2

Y = 2s + 1(s + 1)2 + 4 + 2(s + 1)2 + 4

y = e−t(2 cos 2t + sin 2t)

↳ check: y(0) = 2, y′(0) = −2 + 2 = 0.

§6.2 — partial fractions

(s − a) → As − a;  cover-up gives A

(s − a)2 → Bs − a + C(s − a)2

no real roots → Bs + Cs2 + …, then complete the square

Table: 1(s − a)2 → teat.

Example: ℒ−1{4(s − 1)(s + 1)2}

As − 1 + Bs + 1 + C(s + 1)2

s = 1: A = 44 = 1;   s = −1: C = 4−2 = −2

s2 terms: A + B = 0  ⇒  B = −1

et − e−t − 2te−t

↳ next: functions that switch on and off.

§6.3 — step functions

uc(t) = 0 for t < c, 1 for t ≥ c

a piece on a ≤ t < b: multiply by ua(t) − ub(t)

ℒ{uc(t)f(t − c)} = e−csF(s)

Before you transform, rewrite what multiplies uc(t) in terms of t − c.

Example: f(t) = 0,  t < 1
t,  1 ≤ t < 3
0,  t ≥ 3

f = tu1(t) − tu3(t)

t = (t − 1) + 1,   t = (t − 3) + 3

f = u1(t)[(t − 1) + 1] − u3(t)[(t − 3) + 3]

ℒ{f} = e−s(1s2 + 1s) − e−3s(1s2 + 3s)

↳ ℒ{u3(t)t} is not e−3s/s2.

§6.4 — a force that switches on

Example: y″ + 4y′ + 3y = 6u1(t),  y(0) = 0,  y′(0) = 0

(s2 + 4s + 3)Y = 6e−ss

Y = e−sH(s),  H = 6s(s + 1)(s + 3)

H = 2s − 3s + 1 + 1s + 3  cover-up, no e−s inside

h(t) = 2 − 3e−t + e−3t

e−sH(s) → u1(t)h(t − 1)

y = u1(t)[2 − 3e−(t − 1) + e−3(t − 1)]

Every t in h becomes t − 1.

↳ the picture: at rest until t = 1, then up to 2.

§6.4 — the picture

0 ≤ t < 1: y = 0, no force yet

t ≥ 1: y rises

t → ∞: y → 2

Why 2: with y″ = y′ = 0, 3y = 6.

↳ now the delta.

§6.5 — the delta function

ℒ{δ(t − c)} = e−cs,   ℒ{δ(t)} = 1

∫0∞ δ(t − c)f(t) dt = f(c)

In ay″ + … = kδ(t − c): y stays continuous, y′ jumps by k/a at t = c.

The method is the same: transform, solve, invert, shift.

Example: y″ + 3y′ + 2y = δ(t − 2),  y(0) = 0,  y′(0) = 0

(s2 + 3s + 2)Y = e−2s

Y = e−2s1(s + 1)(s + 2) = e−2s(1s + 1 − 1s + 2)

y = u2(t)[e−(t − 2) − e−2(t − 2)]

at t = 2: y = 0 on both sides,  y′ jumps from 0 to 1
