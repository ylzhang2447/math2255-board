Why erx fails for y″ − xy = 0

try y = erx:  y″ = r2erx

r2erx − xerx = 0

(r2 − x)erx = 0  ⇒  r2 = x

r must be a constant, but here it would have to change with x. No constant r works.

A new guess: a power series

y = a0 + a1x + a2x2 + a3x3 + …

Infinitely many unknown numbers a0, a1, a2, … instead of one r.

Before we use it, we need three facts: when such a sum has a value, how to differentiate it, and how to compare two of them. That is §5.1.

↳ first, the definition.

§5.1 — power series

∞∑n=0an(x − x0)n = a0 + a1(x − x0) + a2(x − x0)2 + …

x0 is the center; an are the coefficients.

partial sum  SN(x) = N∑n=0an(x − x0)n

The series converges at x if limN→∞ SN(x) exists and is finite. Otherwise it diverges at x.

At x = x0 every term after a0 is 0: every power series converges at its center.

Example: ∞∑n=0xn  (center 0, every an = 1)

SN = 1 + x + … + xN = 1 − xN+11 − x

|x| < 1:  xN+1 → 0, so SN → 11 − x

|x| ≥ 1:  the terms xn do not go to 0: diverges

∞∑n=0xn = 11 − x,   −1 < x < 1

↳ it converges on an interval around the center.

The radius of convergence

Every power series has a radius ρ

|x − x0| < ρ:  converges

|x − x0| > ρ:  diverges

ρ = 0: only at x0.  ρ = ∞: at every x. At |x − x0| = ρ the series must be checked separately; we will not need those two points.

The ratio test finds ρ

|an+1(x − x0)n+1||an(x − x0)n| = |an+1||an| |x − x0|

L = limn→∞ |an+1||an|:  converges when L|x − x0| < 1

ρ = 1L   (L = 0: ρ = ∞;  L = ∞: ρ = 0)

↳ two examples.

Example 1 — two radii

∞∑n=1(x − 2)nn 3n

center 2,  an = 1n 3n

|an+1||an| = n 3n(n + 1)3n+1 = 13·nn + 1 → 13

ρ = 3:  converges for −1 < x < 5

∞∑n=0xnn!

|an+1||an| = n!(n + 1)! = 1n + 1 → 0

ρ = ∞:  converges for every x

This series is ex. We will see why in a moment.

Taylor series

f(x) = ∞∑n=0f(n)(x0)n!(x − x0)n

f is analytic at x0 if this series converges to f on an interval around x0.

Polynomials, ex, sin x, cos x are analytic at every point. A rational function is analytic except where its denominator is 0.

Series we will recognize (center 0)

ex = 1 + x + x22! + x33! + …

cos x = 1 − x22! + x44! − …

sin x = x − x33! + x55! − …

↳ next: how to differentiate a series.

Differentiating term by term

For |x − x0| < ρ we may differentiate term by term. The radius stays the same.

y = a0 + a1x + a2x2 + a3x3 + … = ∞∑n=0anxn

y′ = a1 + 2a2x + 3a3x2 + … = ∞∑n=1nanxn−1

y″ = 2a2 + 6a3x + 12a4x2 + … = ∞∑n=2n(n − 1)anxn−2

The constant a0 has derivative 0, so y′ starts at n = 1 and y″ at n = 2.

Check with ex = ∞∑n=0xnn!

(ex)′ = ∞∑n=1n xn−1n! = ∞∑n=1xn−1(n − 1)!

= 1 + x + x22! + … = ex  ✓

↳ the powers are xn−1 and xn−2, not xn. That makes adding hard.

Shifting the index

∞∑n=2n(n − 1)anxn−2

let k = n − 2:  n = k + 2;  n = 2 means k = 0

= ∞∑k=0(k + 2)(k + 1)ak+2xk

rename k as n:  ∞∑n=0(n + 2)(n + 1)an+2xn

The same terms, written two ways

n = 2, 3, 4:  2·1 a2 + 3·2 a3x + 4·3 a4x2 + …

n = 0, 1, 2:  2·1 a2 + 3·2 a3x + 4·3 a4x2 + …

Inside: n → n + 2.  Start: 2 → 0.

Add the same number inside that you subtract from the start.

Equal series, equal coefficients

If ∞∑n=0cnxn = 0 for every x near 0, then every cn = 0.

Why

put x = 0:  c0 = 0

differentiate, put x = 0:  c1 = 0

differentiate again, put x = 0:  2c2 = 0

Each derivative at 0 gives exactly one coefficient.

Adding two series

Both must have the same power xn and the same starting n. Then add the coefficients.

∞∑n=0bnxn + ∞∑n=1cnxn = b0 + ∞∑n=1(bn + cn)xn

Write the extra first terms separately before you add.

↳ now a first equation solved with a series.

Example 2 — y′ + y = 0 with a series

y = ∞∑n=0anxn,  y′ = ∞∑n=1nanxn−1

shift:  y′ = ∞∑n=0(n + 1)an+1xn

y′ + y = ∞∑n=0[(n + 1)an+1 + an]xn = 0

every coefficient is 0:  (n + 1)an+1 + an = 0

an+1 = −ann + 1,  n ≥ 0

a1 = −a0,  a2 = −a12 = a02!,  a3 = −a23 = −a03!

an = (−1)na0n!

y = a0(1 − x + x22! − x33! + …)

y = a0e−x

The formula an+1 = … is a recurrence relation: each coefficient comes from the one before.

↳ the same answer as chapter 2. Now second order.

§5.2 — series solutions near an ordinary point

P(x)y″ + Q(x)y′ + R(x)y = 0,  P, Q, R polynomials

x0 is an ordinary point if P(x0) ≠ 0. Near x0 we may divide by P.

x0 is a singular point if P(x0) = 0.

Example: (1 − x2)y″ + xy′ + y = 0

P = 1 − x2 = 0 at x = ±1

0 is ordinary;  ±1 are singular

The method at x0 = 0

  1. y = ∞∑n=0anxn; write y′ and y″.
  2. Plug in. Multiply any x into its series.
  3. Shift every series to xn.
  4. Same starting n: write the extra terms separately.
  5. Every coefficient = 0: the recurrence.
  6. a0, a1 are free: y = a0y1 + a1y2.

↳ first, an equation we already know.

Example 3 — y″ + y = 0, x0 = 0

y″ = ∞∑n=2n(n − 1)anxn−2 = ∞∑n=0(n + 2)(n + 1)an+2xn

y″ + y = ∞∑n=0[(n + 2)(n + 1)an+2 + an]xn = 0

an+2 = −an(n + 2)(n + 1),  n ≥ 0

Each coefficient comes from the one two steps back: a0 starts the even ones, a1 the odd ones.

n = 0:  a2 = −a02·1 = −a02!

n = 2:  a4 = −a24·3 = a04!

n = 1:  a3 = −a13·2 = −a13!

n = 3:  a5 = −a35·4 = a15!

y = a0(1 − x22! + x44! − …) + a1(x − x33! + x55! − …)

y = a0 cos x + a1 sin x

↳ chapter 3 gives the same: r = ±i.

Example 4 — y″ − xy = 0, the recurrence

y″ = ∞∑n=0(n + 2)(n + 1)an+2xn

xy = ∞∑n=0anxn+1 = ∞∑n=1an−1xn

The first series starts at n = 0, the second at n = 1. Write the n = 0 term of the first separately: 2·1 a2.

2a2 + ∞∑n=1[(n + 2)(n + 1)an+2 − an−1]xn = 0

constant term:  2a2 = 0,  so a2 = 0

xn, n ≥ 1:  (n + 2)(n + 1)an+2 = an−1

an+2 = an−1(n + 2)(n + 1),  n ≥ 1

Now each coefficient comes from the one three steps back.

Example 4 — the coefficients

n = 1:  a3 = a03·2 = a06

n = 4:  a6 = a36·5 = a0180

n = 2:  a4 = a14·3 = a112

n = 5:  a7 = a47·6 = a1504

n = 3:  a5 = a25·4 = 0, so a8 = a11 = … = 0

y = a0(1 + x36 + x6180 + …) + a1(x + x412 + x7504 + …)

y = a0y1(x) + a1y2(x)

These are not ex, sin, or cos. The series itself is the answer.

y1(0) = 1, y1′(0) = 0;  y2(0) = 0, y2′(0) = 1

So a0 = y(0) and a1 = y′(0), and W(y1, y2)(0) = 1 ≠ 0.
