ℒ{tn}

ℒ{tn} = n!sn+1,   s > 0,  n = 0, 1, 2, …

Why: by parts, u = tn

ℒ{tn} = [−tnse−st]0∞ + ns∫0∞tn−1e−stdt

= nsℒ{tn−1}  the bracket is 0 for n ≥ 1

Each step lowers the power by one and brings out a factor n/s.

Repeat until t0 = 1

n = 1:  1s2;   n = 2:  2s3;   n = 3:  6s4

The shift rule

ℒ{eatf(t)} = F(s − a)

Why: one line

∫0∞e−steatf(t) dt = ∫0∞e−(s − a)tf(t) dt

The right side is the definition of F, with s − a in place of s.

If F(s) exists for s > c, the shifted one exists for s > c + a.

How to use it

1. Find F(s) for f alone, from the table.

2. Replace every s by s − a.

ℒ{eat} = 1s − a is this rule with f = 1

↳ two examples.

↳ the main reason for the transform.

The transform of a derivative

f continuous, f′ piecewise continuous, both of exponential order a,  s > a

By parts: u = e−st, dv = f′ dt

∫0Ae−stf′(t) dt = [e−stf(t)]0A + s∫0Ae−stf(t) dt

[…]0A = e−sAf(A) − f(0) → 0 − f(0)  exponential order, s > a

let A → ∞:  ℒ{f′} = −f(0) + sℒ{f}

ℒ{f′} = sℒ{f} − f(0)

A derivative in t becomes multiplication by s, minus the initial value.

The initial value appears by itself. We never have to add it later.

↳ the second derivative: use the rule twice.

The second derivative

ℒ{f″} = ℒ{(f′)′}

Apply the rule to f′

ℒ{f″} = sℒ{f′} − f′(0)

Then to f

= s(sℒ{f} − f(0)) − f′(0)

ℒ{f″} = s2ℒ{f} − sf(0) − f′(0)

Both initial values of a second-order problem appear: f(0) and f′(0).

The power of s goes down as the order of the derivative goes down.

↳ a check with a function we know.

Example 2 — checking the formula

f = sin t,   f″ = −sin t,   f(0) = 0,   f′(0) = 1

Directly from the table

ℒ{−sin t} = −1s2 + 1

From the formula

s2·1s2 + 1 − s·0 − 1 = s2 − (s2 + 1)s2 + 1

= −1s2 + 1  ✓

The same answer. The −f′(0) term was needed: without it the formula would give the wrong function.

↳ now a differential equation.

Example 3 — transforming an initial value problem

y″ − y′ − 2y = 0,   y(0) = 1,   y′(0) = 0

Transform each term; write Y(s) = ℒ{y}

ℒ{y″} = s2Y − s·1 − 0

ℒ{y′} = sY − 1

(s2Y − s) − (sY − 1) − 2Y = 0

Solve for Y: this is algebra

(s2 − s − 2)Y = s − 1

Y(s) = s − 1(s − 2)(s + 1)

The factor s2 − s − 2 is the characteristic polynomial from chapter 3.

The initial conditions are already inside Y. There are no constants c1, c2 to find.

To get y(t) we need the inverse transform: Friday. The answer will be 13e2t + 23e−t.

↳ with a forcing on the right side.

Example 4 — with a forcing

y″ + y = et,   y(0) = 1,   y′(0) = 0

Transform both sides

(s2Y − s·1 − 0) + Y = 1s − 1

(s2 + 1)Y = s + 1s − 1

Y(s) = ss2 + 1 + 1(s − 1)(s2 + 1)

The first term comes from the initial values; the second from the forcing et.

In chapter 3 these were yc and Y. Here both come out of one calculation.
