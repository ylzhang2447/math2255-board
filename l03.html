Where we got to

You solved three equations on Friday. They all came out the same shape.

y = (equilibrium) + c e(rate) t

And the method was: separate, integrate, solve for y.

↳ that worked because every one of them had a plain number in front of the y

The general first order linear equation

dydt + p(t) y = g(t)  standard form

Linear, because y and y′ appear by themselves.

But p and g can be anything. Constants, powers of t, exponentials, sines.

Why Friday's method dies here

dydt = −p(t) y + g(t)  the right side will not split into (t stuff)(y stuff)

↳ so we need a genuinely new idea, not a harder version of the old one

The whole derivation

We want the left side to be one derivative, so we can undo it.

y′ + p y  two terms

Product rule

(μy)′ = μy′ + μ′y

So multiply everything by μ

μy′ + μp y  ← ours

μy′ + μ′y  ← product rule

same when  μ′ = pμ

↳ μ is not a guess. It is whatever solves that.

Then the equation is

(μy)′ = μg

μy = ∫μg dt + c

y = 1μ (∫μg dt + c)

↳ the c is born here, so it is divided by μ too

And μ′ = pμ is separable

μ′μ = p,   and  μ′μ = (ln|μ|)′

ln|μ| = ∫p dt

μ = e∫p dt

μ = k e∫p dt  from the +C

k multiplies both sides ⇒ it cancels ⇒ take k = 1

The recipe

  1. Put it in standard form:  y′ + p(t)y = g(t). Read p from it.
  2. Build  μ = e∫p dt.
  3. Write  (μy)′ = μg  immediately. You may skip the line before it.
  4. Integrate both sides, then divide by μ.

The c appears in step 4, and it is divided by μ too.

All four steps in one line

y = 1μ (∫μg dt + c),   μ = e∫p dt

↳ you can always check an answer by putting it back into the equation

Example 1

y′ + 2y = 4  already in standard form, so p = 2

Step 1  build μ

μ = e∫2 dt = e2t

Step 2  multiply through by μ

e2ty′ + 2e2ty = 4e2t

⇒  (e2ty)′ = 4e2t  left side is a product rule

Steps 3 and 4  integrate, then divide by μ

e2ty = 2e2t + c

y = 2 + c e−2t

↳ equilibrium 2, negative exponent: it settles down — Friday’s picture.

What Example 1 looks like

y′ + 2y = 4  the same equation, drawn instead of solved

Every curve is y = 2 + ce−2t for one value of c. The flat one is c = 0.

The c you solve for is which curve you are on.

Example 2

y′ − 3y = et  watch the sign: p = −3

μ = e∫−3 dt = e−3t

(e−3ty)′ = et · e−3t = e−2t

↳ the two exponentials combine. That is the whole reason this works.

e−3ty = −12e−2t + c

y = −12et + c e3t

Find the general solution. Use the four steps on the left of the board.

1.  y′ + 3y = 6

2.  y′ − y = 2e2t  mind the sign of p

3.  y′ + 4y = 8,   y(0) = 5  this one has an initial condition

Problems 1 and 2 — answers

1.  μ = e3t   (e3ty)′ = 6e3t

   e3ty = 2e3t + c   ⇒   y = 2 + c e−3t

2.  p = −1,  μ = e−t   (e−ty)′ = 2e2te−t = 2et

   e−ty = 2et + c   ⇒   y = 2e2t + c et

↳ in 2 the c got multiplied by et, not by e2t. Dividing by μ is what decides that.

Problem 3 — answer

y′ + 4y = 8,  y(0) = 5

First the general solution

μ = e4t   ⇒   y = 2 + c e−4t

Then put t = 0 in

5 = 2 + c e0 = 2 + c   ⇒   c = 3

y = 2 + 3 e−4t

↳ general solution first, initial condition second. Never the other way round.

Example 3 — not in standard form yet

2y′ + 6y = 12,  y(0) = 1

There is a 2 in front of y′. Divide the whole equation by it first.

y′ + 3y = 6  now p = 3, and you can read it off

μ = e3t   ⇒   (e3ty)′ = 6e3t   ⇒   y = 2 + c e−3t

y(0) = 1:   1 = 2 + c   ⇒   c = −1

y = 2 − e−3t

↳ if you skip the dividing, you get μ = e6t and everything after it is wrong

Problems 4 to 6 — answers

4.  divide by 3:  y′ + 2y = 4   ⇒   y = 2 + c e−2t

5.  p = −2,  μ = e−2t   (μy)′ = 4et

   μy = 4et + c   ⇒   y = 4e3t + c e2t

6.  divide by 2:  y′ + 12y = 2,  μ = et/2

   y = 4 + c e−t/2,   y(0) = 6 ⇒ c = 2   ⇒   y = 4 + 2e−t/2

Every one of them: equilibrium + c e(rate) t.

↳ bonus: 7. y = (t + c)e−t   8. y = 3 − 3e−t/2

Example 4 — a different shape

y′ + 2y = 3e−2t  same left side as Example 1

μ = e2t   ⇒   (e2ty)′ = 3e−2t · e2t

                 (e2ty)′ = 3  the exponentials cancel completely

e2ty = 3t + c

y = (3t + c) e−2t

↳ no equilibrium this time, and a t appears out of nowhere

And what Example 4 looks like

y′ + 2y = 3e−2t  the right side has a t in it now

No horizontal line anywhere. Every solution slides to zero, and none of them stays put.

A t on the right means the field tilts as you move across.

Problems 9 to 11 — answers

9.  μ = e3t   (μy)′ = 5   ⇒   y = (5t + c)e−3t

10.  p = −1, μ = e−t   (μy)′ = 4   ⇒   y = (4t + c)et

11.  (μy)′ = 6   ⇒   y = (6t + c)e−2t

    y(0) = 1:  1 = (0 + c)·1   ⇒   y = (6t + 1)e−2t

The rule behind all three

When g is e−pt, the μ kills it and you integrate a constant.
